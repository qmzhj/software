# 应用说明

校园通是一个面向高校师生的校园通讯与信息服务平台，基于 Flask + SQLite 构建后端服务，前端采用纯静态 HTML 页面实现交互界面。系统围绕校园通讯与信息查询两大核心需求，提供即时通讯、群组聊天、公告发布、校园信息查询等功能模块。

系统采用预置用户注册机制，由管理员通过 users.json 批量导入师生账号信息（学工号、姓名），用户首次使用前需通过学工号与姓名匹配验证完成注册激活，设置登录密码后方可进入系统。注册时系统根据学工号编码规则自动识别用户角色（学生、教职工、管理员），并为用户初始化即时聊天、私聊、课程三类系统默认群组。登录采用 Token 认证机制，密码经 SHA-256 哈希加密后存储，登录失败超过5次将触发账户临时锁定。

即时通讯功能涵盖私聊与群聊两种模式。私聊为一对一消息通信，支持文字消息发送与2分钟内的消息撤回。群聊基于聊天室实现，用户在群组内可创建多个聊天室进行主题讨论，聊天室支持成员管理与角色分配（管理员、普通成员），群组分为系统预设群组（即时聊天、私聊、课程）和用户自定义群组两类。消息加载通过前端定时轮询实现消息实时更新。

公告功能允许教师和管理员发布校园公告，支持标题、正文、发布单位和文件附件，附件上传上限为 500MB。公告发布后支持按创建时间倒序排列展示，仅发布者可修改或删除。

校园信息查询功能提供空闲教室查询、课程表查询、校园活动查询、教师值班查询和教师办公信息查询，数据通过预置脚本导入数据库，方便师生获取校园公共服务信息。

系统当前为开发版本，Token 存储在服务端内存中，服务重启后所有登录状态失效。短信验证码固定为 123456 用于开发测试，生产环境需部署 HTTPS 并替换为正式验证码服务。
