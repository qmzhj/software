# 应用说明

校园通是一个面向高校师生的校园通讯与信息服务平台，基于 Flask + SQLite 构建后端服务，前端采用纯静态 HTML 页面实现交互界面。系统围绕校园通讯与信息查询两大核心需求，提供即时通讯、群组管理、公告发布、校园信息查询等功能模块。

## 用户系统

系统采用预置用户注册机制，由管理员通过 users.json 批量导入师生账号信息（学工号、姓名），用户首次使用前需通过学工号与姓名匹配验证完成注册激活，设置登录密码后方可进入系统。注册时系统根据学工号编码规则自动识别用户角色（学生、教职工、管理员），并为用户初始化即时聊天、私聊、课程、班级四类系统默认群组。登录采用 Token 认证机制，密码经 SHA-256+SALT 哈希加密后存储，登录失败超过 5 次将触发账户临时锁定 30 分钟。支持手机号绑定、忘记密码（短信验证码验证后重置密码）。

## 即时通讯

涵盖私聊与群聊两种模式。私聊为一对一消息通信，支持文字、图片、视频、文件等多种消息类型，文件上传上限 500MB，支持 2 分钟内消息撤回（管理员不限时）。
群聊基于聊天室实现，分为系统聊天室和用户自定义聊天室，课程、赛事、班级、自定义的聊天室详情界面各不相同，用户可在群组内可创建多个聊天室，支持聊天室管理、发布公告。
群组同样分为系统预设群组（即时聊天、私聊、课程、班级）和用户自定义群组两类。消息实时推送通过 SSE（Server-Sent Events）长连接实现，替代了原先的定时轮询方式。

## 通知中心

集中管理好友申请、聊天室邀请和系统通知（拉黑通知、取消好友通知等），支持标记已读、批量已读、删除通知、锁定通知（系统通知不可删除时锁定）。好友申请和聊天室邀请支持在线审批（同意/拒绝），审批通过后自动执行后续操作。

## 好友与黑名单

支持搜索用户并添加好友，好友关系双向确认。黑名单功能可屏蔽指定用户的消息，拉黑后自动过滤私聊和群聊中的消息。

## 校园信息查询

提供多词条用户查询、课程表查询（支持按周次切换的日历视图）、校园赛事活动查询、公告查询。课程表同时支持学生和教师视角，教师可查看自己所授课程。数据通过预置 JSON 脚本导入数据库。

赛事可自行组队，管理小队

## 班级与课程群组

系统根据 class.json 自动创建班级聊天室和年级群，根据 lessons.json 自动创建课程聊天室并将选课学生和授课教师加入。启动时自动同步数据，确保班级成员和课程成员信息最新。
