# 状态图（STD）分析

## 1. 用户账号生命周期

```
                  ┌─────────────────────────────┐
                  │          users.json          │
                  │           (预载)              │
                  └─────────────┬───────────────┘
                                │ 批量导入数据库
                                ▼
                  ┌─────────────────────────────┐
                  │       已入库未注册             │
                  │       (registed=0)           │
                  └─────────────┬───────────────┘
                                │ 注册：输入学号+姓名+密码
                                │ 验证学号姓名匹配
                                ▼
                  ┌─────────────────────────────┐
                  │          已注册               │ ◄──────────────┐
                  │       (registed=1)           │                │
                  └─────────────┬───────────────┘                │
                                │                                │
                 ┌──────────────┴──────────────┐                 │
                 │                              │                │
            ┌────▼────┐                  ┌──────▼───────┐       │
            │ 正常登录 │                  │ 密码错误×5    │       │
            └─────────┘                  └──────┬───────┘       │
                                                 │               │
                  ┌─────────────────────────────┐ │               │
                  │          已锁定              │◄┘               │
                  │  (locked=1, unlock_time=    │                 │
                  │   now+30min)                │                 │
                  └─────────────┬───────────────┘                 │
                                │ 30分钟后自动解锁                  │
                                └─────────────────────────────────┘
```

| 转移 | 源状态 | 目标状态 | 触发条件 | 守卫条件 |
|------|--------|----------|----------|----------|
| 导入 | 预载 | 已入库未注册 | 系统启动时从 users.json 读取 | 用户不在数据库中 |
| 注册 | 已入库未注册 | 已注册 | 提交注册表单 | 学号存在且姓名匹配；密码满足复杂度要求 |
| 锁定 | 已注册 | 已锁定 | login_fails >= 5 | 密码连续错误5次 |
| 解锁 | 已锁定 | 已注册 | 等待30分钟 | unlock_time <= now |

**相关字段**: `registed`, `locked`, `unlock_time`, `login_fails`

## 2. 聊天室成员角色

```
                    ┌──────────┐
         ┌─────────►│  群主     │◄──────────┐
         │          │ (admin)  │           │
         │          └──────────┘           │
         │                                │
         │  创建聊天室时指定                 │ 不可修改，不可踢出
         │                                │
    ┌────┴──────┐              ┌──────────┴───┐
    │  普通成员   │              │   管理员      │
    │ (member)   │─────────────►│ (manager)    │
    └────────────┘ 群主设为管理  └──────────────┘
                                                  │
                         ◄─────────────────────────┘
                          群主取消管理
```

| 转移 | 源状态 | 目标状态 | 触发条件 | 守卫条件 |
|------|--------|----------|----------|----------|
| 设置管理 | 普通成员 | 管理员 | 群主调用 /api/groups/\<id\>/admin (action=set) | 操作者必须是 admin |
| 取消管理 | 管理员 | 普通成员 | 群主调用 /api/groups/\<id\>/admin (action=unset) | 操作者必须是 admin |
| 踢出 | 普通成员/管理员 | 无(删除成员) | 群主调用 /api/groups/\<id\>/kick | 不能踢出 admin，不能踢出自己 |
| 退出 | 任意角色 | 无(删除成员) | 成员调用 /api/groups/\<id\>/leave | 群主仅当群内只有自己时可退出 |

**角色权限**:

| 操作 | admin | manager | member |
|------|-------|---------|--------|
| 踢出成员 | ✔ | ✘ | ✘ |
| 设置/取消管理 | ✔ | ✘ | ✘ |
| 修改聊天室名称 | ✔ | ✔ | ✘ |
| 发布公告 | ✔ | ✔ | ✘ |
| 退出聊天室 | 仅剩自己时 | ✔ | ✔ |

## 3. 消息状态

```
  ┌──────────┐    发送者2分钟内撤回    ┌──────────┐
  │  已发送   │──────────────────────►│  已撤回   │
  │ (sent)   │                       │ (revoked)│
  └──────────┘                       └──────────┘
```

| 转移 | 源状态 | 目标状态 | 触发条件 | 守卫条件 |
|------|--------|----------|----------|----------|
| 发送 | 初始 | 已发送 | POST /api/send 或 /api/groups/\<id\>/send | 消息内容非空 |
| 撤回 | 已发送 | 已撤回 | POST /api/messages/revoke/\<id\> | 发送者本人操作；time.time() - timestamp <= 120秒 |

**消息类型**: text（文本）、image（图片）、file（文件）、system（系统消息，由后端自动生成）

## 4. 好友关系

```
  ┌──────────┐    一方添加好友    ┌──────────┐
  │  非好友   │────────────────►│  已是好友  │
  │          │◄────────────────│          │
  └──────────┘    一方删除好友   └──────────┘
```

| 转移 | 源状态 | 目标状态 | 触发条件 | 守卫条件 |
|------|--------|----------|----------|----------|
| 添加好友 | 非好友 | 已是好友 | POST /api/friends/add | 不能添加自己；用户存在；尚未是好友 |
| 删除好友 | 已是好友 | 非好友 | POST /api/friends/remove | 已是好友关系 |

## 5. 黑名单

```
  ┌──────────┐    拉黑    ┌──────────┐
  │  正常     │──────────►│  已拉黑   │
  │          │◄──────────│          │
  └──────────┘  取消拉黑   └──────────┘
```

| 转移 | 源状态 | 目标状态 | 触发条件 | 守卫条件 |
|------|--------|----------|----------|----------|
| 拉黑 | 正常 | 已拉黑 | POST /api/blacklist/add | 不能拉黑自己 |
| 取消拉黑 | 已拉黑 | 正常 | POST /api/blacklist/remove | 已在黑名单中 |

**影响**: 若 A 拉黑 B，A 的消息列表中不会显示 B 的消息（包括私聊和群聊）。

## 6. 群组（User Group）生命周期

```
  ┌──────────┐    创建群组    ┌──────────┐    创建者删除    ┌──────────┐
  │  初始     │─────────────►│   活跃    │───────────────►│  已删除   │
  └──────────┘              └──────────┘                └──────────┘
                                  │
                                  │ 添加/移除聊天室
                                  │ 添加/移除成员
                                  ▼
                              状态不变
```

| 转移 | 源状态 | 目标状态 | 触发条件 | 守卫条件 |
|------|--------|----------|----------|----------|
| 创建 | 初始 | 活跃 | POST /api/user-groups | 名称非空 |
| 删除 | 活跃 | 已删除 | DELETE /api/user-groups/\<id\> | 创建者本人操作；系统群组不可删除 |

**群组类型**:
- `system`: 系统自动创建（即时聊天、私聊、课程），不可删除
- `custom`: 用户自定义创建
