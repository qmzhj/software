# 5.2 ER图说明

## 主要实体关系：

### 用户与好友/黑名单关系
- **User 与 User 是多对多关系（通过 friends 关联表）**：一个用户可以拥有多个好友。
- **User 与 User 是多对多关系（通过 blacklist 关联表）**：一个用户可以屏蔽多个用户。

### 用户与会话（聊天室）关系
- **User 与 groups_chat 是多对多关系（通过 group_members 关联表）**：一个用户可以加入多个聊天室，一个聊天室包含多个用户。
- **groups_chat 与 group_members 是一对多关系**：一个聊天室可以有多个成员。
- **group_members 与 User 是多对一关系**：多个成员记录对应一个用户。

### 用户与群组关系
- **User 与 user_groups 是多对多关系（通过 user_group_members 关联表）**：一个用户可以加入多个群组，一个群组包含多个用户。
- **user_groups 与 user_group_members 是一对多关系**：一个群组可以有多个成员。
- **user_group_members 与 User 是多对一关系**：多个成员记录对应一个用户。

### 群组与聊天室关系
- **user_groups 与 groups_chat 是多对多关系（通过 user_group_chats 关联表）**：一个群组可以关联多个聊天室。

### 消息关系
- **User 与 messages 是一对多关系**：一个用户可以发送多条私聊消息。
- **groups_chat 与 group_messages 是一对多关系**：一个聊天室可以包含多条群聊消息。
- **User 与 group_messages 是一对多关系（sender）**：一个用户可以发送多条群聊消息。

### 课程与用户关系
- **User 与 lesson 是一对多关系（教师授课）**：一个教师可以讲授多门课程。
- **User 与 lesson 是多对多关系（通过 lesson_stu 关联表）**：一个学生可以选修多门课程，一门课程可以被多个学生选修。

### 教室与课程关系
- **Classroom 与 course_schedule 是一对多关系**：一个教室可以被安排多个时间段的课程。

### 办公室关系
- **User 与 teacher_office 是一对一关系**：一个老师对应一个办公室信息。

### 值班关系
- **User 与 tutor_duty 是一对多关系**：一个老师可以安排多次值班。

### 公告关系
- **User 与 announcements 是一对多关系**：一个用户可以发布多条公告。

# 5.3 实体类清单

| 实体类名 | 描述 | 主要属性 |
| :--- | :--- | :--- |
| **User（用户）** | 系统的用户实体，包括学生、教职工和管理人员 | userId（用户ID）、studentStaffId（学工号）、name（姓名）、password（密码）、role（角色）、department（所属部门/学院）、email（邮箱）、phone（电话）、avatar（头像）、isLocked（是否锁定）、loginErrorCount（登录错误次数）、unlockTime（解锁时间） |
| **Message（私聊消息）** | 用户之间发送的即时消息 | messageId（消息ID）、senderId（发送者ID）、receiverId（接收者ID/群组ID）、messageType（消息类型）、content（消息内容）、attachmentPath（附件路径）、sendTime（发送时间）、status（消息状态）、isRead（是否已读） |
| **groups_chat（聊天室/会话）** | 用户之间的聊天会话 | sessionId（会话ID）、sessionType（会话类型）、creatorId（创建者ID）、groupName（群名称）、createTime（创建时间）、groupType（群组类型）、relatedId（关联ID，如课程ID、班级ID） |
| **group_members（会话成员）** | 聊天室与成员的关系 | sessionId（会话ID）、memberId（成员ID）、joinTime（加入时间）、memberRole（成员角色）、lastReadTime（最后阅读时间） |
| **Announcement（公告）** | 系统发布的官方公告 | announcementId（公告ID）、title（标题）、content（正文）、publisherId（发布者ID）、department（所属部门）、publishTime（发布时间）、attachmentPaths（附件路径列表）、lastModifyTime（最后修改时间）、lastModifierId（最后修改者ID） |
| **user_groups（群组）** | 系统中的群组容器 | groupId（群组ID）、groupName（群组名称）、groupType（群组类型）、creatorId（创建者ID）、createTime（创建时间）、relatedId（关联ID） |
| **GroupMember（群组成员）** | 群组与成员的关系 | groupId（群组ID）、memberId（成员ID）、joinTime（加入时间）、memberRole（成员角色） |
| **Classroom（教室）** | 校园教室信息 | classroomId（教室ID）、classroomNo（教室编号）、building（教学楼）、floor（楼层）、capacity（座位数）、hasMultimedia（是否有多媒体设备） |
| **Course（课程）** | 课程信息 | courseId（课程ID）、courseName（课程名称）、teacherId（授课教师ID）、classroomId（教室ID）、schedule（上课时间安排）、semester（学期） |
| **DutySchedule（值班）** | 辅导老师值班信息 | dutyId（值班ID）、teacherId（老师ID）、dutyDate（值班日期）、dutyTime（值班时间）、dutyLocation（值班地点）、contactInfo（联系方式） |
| **Office（办公室）** | 老师办公室信息 | officeId（办公室ID）、teacherId（老师ID）、officeLocation（办公室位置）、department（部门） |

> **注**：原描述中的 `CallRecord`（通话记录）、`Permission`（权限）、`RolePermission`（角色权限）及 `Event`（赛事活动）在当前 ER 图中未体现，已移除。`Session` 实体对应图中的 `groups_chat`。
