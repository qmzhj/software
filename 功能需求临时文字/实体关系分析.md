## 6. 关系摘要

| 实体A | 关系 | 实体B | 说明 |
|-------|------|-------|------|
| users | 1:N | messages | 用户发送/接收私聊消息 |
| users | M:N | users | 好友关系（通过 friends 关联表） |
| users | M:N | users | 黑名单（通过 blacklist 关联表） |
| users | 1:N | announcements | 用户发布公告 |
| users | M:N | groups_chat | 用户加入聊天室（通过 group_members） |
| users | M:N | user_groups | 用户加入群组（通过 user_group_members） |
| users | 1:N | lesson | 教师授课 |
| users | M:N | lesson | 学生选课（通过 lesson_stu） |
| users | 1:1 | teacher_office | 教师办公室信息 |
| groups_chat | 1:N | group_members | 聊天室包含成员 |
| groups_chat | 1:N | group_messages | 聊天室包含消息 |
| user_groups | M:N | groups_chat | 群组包含聊天室（通过 user_group_chats） |
| user_groups | 1:N | user_group_members | 群组包含成员 |
| classrooms | 1:N | course_schedule | 教室被安排课程 |

## 7. 绘制 ER 图指导

### 7.1 符号说明（Chen 表示法 / Crow's Foot）

建议使用 **Crow's Foot 表示法**（最直观）或 **Chen 表示法**：

| 符号 | 含义 |
|------|------|
| ─── | 1（一对一） |
| ──< | 1（一对多，"1"端） |
| ──< | N（一对多，"多"端） |
| ──< | M:N（多对多） |

### 7.2 ER 图绘制步骤

1. **确定核心实体**：users 是所有关系的中心，放在图中央
2. **先画强实体**：users、groups_chat、user_groups、lesson、announcements、classrooms
3. **再画关联实体**：group_members、group_messages、friends、blacklist、lesson_stu、user_group_members、user_group_chats——这些是"菱形"关系
4. **最后画弱实体**：course_schedule、tutor_duty、events（依附于其他实体存在）

### 7.3 分层绘制建议

鉴于实体较多（18个），建议分层绘制：

- **Layer 1 — 用户与社交关系**：users、friends、blacklist、messages
- **Layer 2 — 群组与聊天**：user_groups、groups_chat、group_members、group_messages、user_group_members、user_group_chats
- **Layer 3 — 课程体系**：lesson、lesson_stu、classrooms、course_schedule、teacher_office、tutor_duty
- **Layer 4 — 信息发布**：announcements、events

### 7.4 标注每个关系的基数

绘制时在每个关系线上标注基数：

```
users ────< messages        （1个用户发送N条消息）
users ────< friends >──── users  （M个用户有N个好友）
groups_chat ────< group_members >──── users  （N个聊天室有M个成员）
user_groups ────< user_group_chats >──── groups_chat  （1个群组包含N个聊天室）
lesson ────< lesson_stu >──── users  （1门课程有N个学生选课）
```

### 7.5 注意事项

- **users 是超级实体**，几乎所有其他实体都直接或间接与 users 关联
- **不强制外键约束**（SQLite 默认关闭），但逻辑上存在引用关系
- **group_messages.sender 可为 'system'**，这是唯一的非 users 引用值
- **groups_chat 与 user_groups 是不同概念**：groups_chat 是聊天房间，user_groups 是群组容器，两者通过 user_group_chats 关联
- **消息撤回**是属性级状态（revoked），非独立实体
- 推荐绘制工具：draw.io、PlantUML、LucidChart
