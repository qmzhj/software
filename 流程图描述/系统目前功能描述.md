# 用户认证（流程图已完成）
- 注册（学号+姓名验证，设置密码）
- 登录（密码校验，错误5次锁定30分钟）
- 忘记密码（验证身份后重置密码）

# 群组
- 系统群组（自动将聊天归类：好友/非好友/未分组聊天室/课程班级聊天室/赛事聊天室）
- 自定义群组管理（创建、删除）

# 聊天室
- 系统聊天室（依据课程/赛事/班级自动创建，不可修改，特殊详情界面）
- 自定义聊天室（权限设置、解散、踢人、设管理员/取消管理员、详情分栏与标签展示）
- 聊天室公告发布与查看（权限检查）

# 消息
- 私聊（一对一即时通讯，弹窗私聊界面，消息历史）
- 消息收发（文本/图片/视频/文件，撤回2分钟时限，合并转发，分条转发，黑名单拦截）
- 通话系统（检查在线，检查通话权限，私聊中非好友不允许通话，振铃/接听/拒绝/挂断）

# 社交关系
- 好友（添加好友、好友请求审批、删除好友）
- 黑名单（拉黑/取消拉黑，被拉黑后消息拦截）

# 校园查询
- 用户查询（五个筛选条件：学号/姓名、课程、班级、身份、赛事，AND组合，身份标签展示）
- 课程表（周次选择，按周展示课程）
- 失物招领（发布帖子，失物/招领分类）

- 赛事活动
    - 赛事展示（预置数据展示，管理员发布赛事）
    - 赛事组队（创建小组、申请加入、组长审批、满员设置与检查、退出小组、搜索成员、显示/隐藏满员小组）

# 系统通知
- 好友申请通知
- 聊天室邀请通知
- 赛事组队申请（申请人→组长，审批/拒绝）
- 被拉黑通知
- 聊天室解散通知

# 个人设置
- 个人资料编辑（头像、简介、手机号）
- 修改密码

# 流程图绘制规划

## 适合独立绘制流程图的模块（有分支逻辑）

| 流程图 | 核心流程 |
|--------|---------|
| 系统初始化 | 启动→检查课程/班级/赛事→创建群组容器→创建聊天室→关联群组与聊天室（已存在则跳过） |
| 消息收发 | 发送→消息类型（文本/图片/视频/文件）→黑名单检查→，→撤回→时限检查（普通用户2min/管理员不限），→转发（合并/分条） |
| 通话系统 | 发起通话→检查在线→检查通话权限（私聊需好友）→振铃→接听/拒绝/超时未接→挂断 |
| 赛事组队 | 创建小组（设人数上限）→申请加入→满员检查→组长审批（同意/拒绝）→满员设置→退出小组 |
| 系统通知与审批 | 发送申请→写入通知(pending)→接收方审批→同意/拒绝→执行后续动作（加好友/加入小组/加入聊天室） |

## 无需单独绘制流程图的模块（线性操作/纯展示）

- 自定义群组管理（创建、删除，无分支）
- 自定义聊天室管理（解散、踢人、设管理，单步操作）
- 聊天室公告（发布+查看，无分支）
- 用户查询（输入条件→提交→展示结果，无状态流转）
- 课程表（纯展示，无用户交互流程）
- 个人设置（编辑→保存，线性操作）
- 好友/黑名单（CRUD，无分支）
- 失物招领（发布→展示，线性操作）
