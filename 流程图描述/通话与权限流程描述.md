# UML 活动图：通话与权限流程（泳道图）

## 1. 图表结构
- **类型**：UML 活动图（Activity Diagram）/ 泳道图
- **布局**：横向 3 泳道，从左到右依次排列
- **泳道标题栏颜色**：
  - 呼叫方（前端）：蓝色
  - 后端服务：黄色
  - 接收方（前端/SSE）：绿色
- **起止节点**：顶部实心黑圆（开始），底部实心黑圆（结束）

## 2. 泳道详情与流程

### 流程一：私聊通话邀请

#### 泳道 1：呼叫方（左侧）
- **节点序列**：
 1. 开始（实心圆）
 2. [在私聊界面点击语音或视频通话按钮]（矩形）
 3. 调用 `POST /api/call/invite` 发送 {target_uid, call_type}
 4. {返回结果}（菱形判断）
    - error → [显示错误（"对方未在线"、"没有通话权限"等）]（矩形）→ 结束
    - success → 步骤 5
 5. [显示"正在呼叫..."界面]（矩形）
 6. {通过 SSE 接收到接收方响应}（菱形判断）
    - 接听 → [进入通话中界面]→ 步骤 7
    - 拒绝 → [显示"对方已拒绝"]→ 结束
    - 超时 120 秒 → [显示"无人接听"]→ 结束
 7. [点击挂断]（矩形，调用 POST /api/call/respond {action='hangup'}）
 8. 结束（实心圆）

#### 泳道 2：后端服务（中间）
- **节点序列**：
 1. {目标在线？}（查 user_heartbeats 15 秒内）→ N → 返回"对方未在线"
 2. {呼叫方是目标好友？}（查 user_relations.is_friend）→ N → 返回"不是好友"
 3. {目标允许呼叫方通话？}（查 user_relations WHERE uid=target_uid AND target_uid=caller AND call_notify=1）→ N → 返回"没有通话权限"
 4. [生成 call_id，创建 active_calls 记录（status='ringing'）]（矩形）
 5. [向 call_events[target_uid] 推送 call_invite 事件]（矩形）
 6. [返回 {call_id} 给呼叫方]（矩形）
 7. {收到接收方 respond}（菱形判断）
    - accept → [call.status='connected'] → [向 call_events[caller] 推送 call_accepted]
    - reject → [call.status='rejected'] → [向 call_events[caller] 推送 call_rejected]
 8. {收到挂断}→ [call.status='ended'] → [向另一方推送 call_hangup]
 9. 结束（实心圆）

#### 泳道 3：接收方（右侧）
- **节点序列**：
 1. [通过 EventSource 连接 /api/call/events]（矩形）
 2. [接收到 call_invite 事件]（矩形）
 3. [弹出来电弹窗，含"接听"/"拒绝"按钮]（矩形）
 4. {用户操作}（菱形判断）
    - 接听 → 调用 respond {action='accept'} → 步骤 5
    - 拒绝 → 调用 respond {action='reject'} → 结束
 5. [进入通话中界面]（矩形）
 6. [点击挂断]→ 调用 respond {action='hangup'}
 7. 结束（实心圆）

### 流程二：群聊通话邀请

#### 泳道 1：呼叫方（左侧）
- **节点序列**：
 1. 开始（实心圆）
 2. [在群聊界面点击通话按钮]（矩形）
 3. [弹出成员列表，call_notify=0 的成员置灰不可选]（矩形）
 4. [勾选可呼叫成员，点击发起通话]（矩形）
 5. 结束（实心圆）

#### 泳道 2：后端服务（中间）
- **节点序列**：
 1. {呼叫方是聊天室成员？}→ N → 403
 2. [查询 group_members 中各成员的 call_notify]（矩形）
 3. [仅向 call_notify=1 的成员发送邀请]（矩形）
 4. {系统聊天室强制 call_notify=1，不可修改}（菱形判断，标注约束）
 5. [为每个可邀请成员创建 call_invite 事件]（矩形）
 6. 结束（实心圆）

### 流程三：通话权限设置

#### 3.1 私聊通话权限

#### 泳道 1：用户（前端）
1. [在设置界面切换某联系人的通话权限开关]（矩形）
2. 调用 POST /api/call/preference 发送 {target_uid, call_notify}

#### 泳道 2：后端服务
1. [写入 user_relations.call_notify]（矩形）
2. [写入 call_preferences 旧表兼容]（矩形）
3. commit

#### 3.2 群聊通话权限

#### 泳道 1：用户（前端）
1. [在聊天室详情面板切换"接收通话邀请"开关]（矩形）
2. 调用 POST /api/groups/{id}/call-setting

#### 泳道 2：后端服务
1. {聊天室存在？}→ N → 404
2. {系统聊天室且 call_notify≠1？}→ Y → 403"系统聊天室强制开启"
3. {用户是成员？}→ N → 403
4. [更新 group_members.call_notify]（矩形）
5. commit

## 3. 跨泳道连接线说明
- 泳道 1 [点击通话按钮] → 向右 → 泳道 2 {权限校验} → 向泳道 1/3 返回结果
- 泳道 2 [推送 call_invite] → 向右 → 泳道 3 [来电弹窗]
- 泳道 3 [接听/拒绝] → 向左 → 泳道 2 [respond 处理]
- 泳道 2 [推送 call_accepted/rejected] → 向右 → 泳道 1 [呼叫方收到响应]
- 泳道 1/3 [挂断] → 向左 → 泳道 2 [hangup 处理]
