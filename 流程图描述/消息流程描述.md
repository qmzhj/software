# UML 活动图：即时消息收发流程（泳道图）

## 1. 图表结构
- **类型**：UML 活动图（Activity Diagram）/ 泳道图
- **布局**：横向 3 泳道，从左到右依次排列
- **泳道标题栏颜色**：
  - 发送方（前端）：蓝色
  - 后端服务：黄色
  - 接收方（前端/SSE）：绿色
- **起止节点**：顶部实心黑圆（开始），底部实心黑圆（结束）

## 2. 泳道详情与流程

### 流程一：发送私聊消息

#### 泳道 1：发送方（左侧）
- **节点序列**：
 1. 开始（实心圆）
 2. [选择联系人进入私聊界面]（矩形）
 3. [输入文本或选择文件]（矩形）
 4. [点击发送]（矩形，文本：POST /api/send 发送 JSON；文件：multipart/form-data 上传）
 5. {发送成功？}（菱形判断）
    - N → [显示错误提示]（矩形）
    - Y → 步骤 6
 6. [消息气泡出现在聊天区域]（矩形）
 7. 结束（实心圆）

#### 泳道 2：后端服务（中间）
- **节点序列**：
 1. {内容非空？}→ N → 400
 2. {接收方存在？}→ N → 404
 3. {发送方未被拉黑？}（查 user_relations.is_blocked）→ Y → 403"你已被此用户拉黑"
 4. [向 messages 表插入记录]（矩形）
 5. commit
 6. [通过 /api/stream 向接收方推送 SSE 事件]（矩形）
 7. 结束（实心圆）

#### 泳道 3：接收方（右侧）
- **节点序列**：
 1. [EventSource 连接 /api/stream（mode=private）]（矩形）
 2. [接收到 SSE onmessage 事件]（矩形）
 3. [调用 loadPrivateMessages() 拉取最新消息]（矩形）
 4. [消息气泡出现]（矩形）
 5. 结束（实心圆）

### 流程二：发送群聊消息

#### 泳道 1：发送方（左侧）
- **节点序列**：
 1. [在群组中选择聊天室进入群聊界面]（矩形）
 2. [输入消息或选择文件，点击发送]（矩形，POST /api/groups/{id}/send）
 3. [消息气泡出现在群聊区域]（矩形）
 4. 结束（实心圆）

#### 泳道 2：后端服务（中间）
- **节点序列**：
 1. {用户是聊天室成员？}→ N → 403
 2. [向 group_messages 表插入记录]（矩形）
 3. commit
 4. [通过 /api/stream 向聊天室其他成员推送 SSE 事件]（矩形）
 5. 结束（实心圆）

#### 泳道 3：群聊其他成员（右侧）
- **节点序列**：
 1. [EventSource 连接 /api/stream（mode=group）]（矩形）
 2. [接收到 SSE onmessage 事件]（矩形）
 3. [调用 loadGroupMessages() 拉取最新消息]（矩形）
 4. [消息气泡出现]（矩形）
 5. 结束（实心圆）

### 流程三：消息撤回

#### 泳道 1：发送方（前端）
- **节点序列**：
 1. 开始（实心圆）
 2. [右键点击已发送消息]（矩形）
 3. {当前用户是发送者，或为 admin/manager？}（菱形判断）
    - N → 菜单中无"撤回"选项 → 结束
    - Y → 步骤 4
 4. [点击"撤回"]（矩形）
 5. 调用撤回 API（私聊：POST /api/messages/revoke/{id}，群聊：POST /api/groups/revoke/{id}）
 6. [消息内容替换为"{用户} 撤回了一条消息"]（矩形）
 7. 结束（实心圆）

#### 泳道 2：后端服务（中间）
- **节点序列**：
 1. {普通用户且消息发送超过 120 秒？}（菱形判断）
    - Y → 403"超过撤回时间"
    - N → 步骤 2
 2. [设置 revoked=1]（矩形）
 3. commit
 4. [通过 SSE 通知对方/群成员刷新消息]（矩形）
 5. 结束（实心圆）

#### 泳道 3：接收方 / 群成员（右侧）
- **节点序列**：
 1. [接收到 SSE 事件]（矩形）
 2. [重新拉取消息列表，原消息位置显示撤回提示]（矩形）
 3. 结束（实心圆）

## 3. 跨泳道连接线说明
- 泳道 1 [点击发送] → 向右 → 泳道 2 [接收消息请求]
- 泳道 2 [SSE 推送] → 向右 → 泳道 3 [接收方收到通知]
- 泳道 2 [返回消息 id] → 向左 → 泳道 1 [消息显示在界面]
- 泳道 1 [点击撤回] → 向右 → 泳道 2 [处理撤回请求]
- 泳道 2 [SSE 推送撤回] → 向右 → 泳道 3 [消息被替换]
