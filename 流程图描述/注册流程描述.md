# UML 活动图：用户注册流程（泳道图）

## 1. 图表结构
- **类型**：UML 活动图（Activity Diagram）/ 泳道图
- **布局**：横向 3 泳道，从左到右依次排列
- **泳道标题栏颜色**：
  - 用户注册页面：蓝色
  - 用户注册服务：黄色
  - 用户数据服务：绿色
- **起止节点**：顶部实心黑圆（开始），底部实心黑圆（结束）

## 2. 泳道详情与流程

### 泳道 1：用户注册页面（左侧）
- **节点序列**：
  1. 开始（实心圆）
  2. [输入学工号]（矩形）
  3. [角色预判提示]（矩形，前端实时根据学工号编码规则匹配并展示角色类型）
  4. [输入姓名]（矩形）
  5. [输入密码]（矩形）
  6. [确认密码]（矩形）
  7. [输入手机号]（矩形，非必填）
  8. [点击注册]（矩形）
  9. {密码格式正确？}（菱形判断，前端正则预校验）
     - N → [显示密码格式错误提示]（矩形）
       - 返回步骤 5（向上箭头）
     - Y → 步骤 10
  10. {两次密码一致？}（菱形判断，前端校验）
      - N → [显示密码不一致提示]（矩形）
        - 返回步骤 5（向上箭头）
      - Y → 步骤 11
  11. [发送注册请求]（矩形，POST /api/register）
  12. {注册成功？}（菱形判断，接收来自泳道 2 的返回结果）
      - Y → 步骤 13
      - N → 步骤 14
  13. [显示"注册成功！请登录"并切换至登录页]（矩形）
  14. [显示错误信息]（矩形，展示后端返回的精准错误提示）
  15. 结束（实心圆）

### 泳道 2：用户注册服务（黄色栏）
- **节点序列**：
  1. 接收注册请求 → [基础参数校验]（矩形，密码格式、两次密码一致性校验）
  2. {参数合法？}（菱形判断）
     - N → 返回泳道 1 的 步骤 12（标注"返回 400：密码格式不合法或两次密码不一致"）
     - Y → 步骤 3
  3. [查询用户数据]（矩形）
     - 输出：→ 泳道 3 的 [查询用户数据]
     - 返回：接收泳道 3 返回的用户数据
  4. {账号存在？}（菱形判断，判断 uid 在 users 表中是否存在）
     - N → 返回泳道 1 的 步骤 12（标注"返回 409：无该学工号"）
     - Y → 步骤 5
  5. {姓名匹配？}（菱形判断，比对录入姓名与数据库预置 name 字段）
     - N → 返回泳道 1 的 步骤 12（标注"返回 409：学工号与姓名不匹配"）
     - Y → 步骤 6
  6. {账号未注册？}（菱形判断，检查 registed 字段是否为 0）
     - N → 返回泳道 1 的 步骤 12（标注"返回 409：该用户已注册"）
     - Y → 步骤 7
  7. [角色判定]（矩形，根据 uid 编码规则自动判定角色 student/teacher/manager）
  8. [密码加密]（矩形，SHA256(password + "CampusFakeSalt2024!") 输出十六进制小写字符串）
  9. [更新用户数据]（矩形，UPDATE SET password, phone, registed=1）
     - 输出：→ 泳道 3 的 [更新用户数据]
  10. [创建默认群组]（矩形，调用 ensure_default_groups(uid) 创建即时聊天、私聊、课程群组）
  11. 返回泳道 1 的 步骤 12（标注"返回 201：{message: '注册成功'}"）

### 泳道 3：用户数据服务（绿色栏）
- **节点序列**：
  1. [查询用户数据]（矩形，SELECT * FROM users WHERE uid=?）
     - 返回用户数据行（含 uid, name, password, role, registed 等字段）
     - 输出至泳道 2
  2. [更新用户数据]（矩形，UPDATE users SET password=?, phone=?, registed=1 WHERE uid=?）
     - 输出至泳道 2
  3. [创建系统群组]（矩形，INSERT INTO user_groups 创建 sys_im_{uid}、sys_private_{uid}、sys_courses_{uid}）
     - 输出至泳道 2

## 3. 跨泳道连接线说明
- 泳道 1 [发送注册请求] → 向右 → 泳道 2 [基础参数校验]
- 泳道 2 [查询用户数据] → 向右 → 泳道 3 [查询用户数据]
- 泳道 3 [查询用户数据] → 向左 → 泳道 2 {账号存在？}
- 泳道 2 {账号不存在} → 向左 → 泳道 1 {注册成功？}（标注：409 无该学工号）
- 泳道 2 {姓名不匹配} → 向左 → 泳道 1 {注册成功？}（标注：409 学工号与姓名不匹配）
- 泳道 2 {账号已注册} → 向左 → 泳道 1 {注册成功？}（标注：409 该用户已注册）
- 泳道 2 {参数不合法} → 向左 → 泳道 1 {注册成功？}（标注：400 密码格式或一致性错误）
- 泳道 2 [更新用户数据] → 向右 → 泳道 3 [更新用户数据]
- 泳道 2 [创建默认群组] → 向右 → 泳道 3 [创建系统群组]
- 泳道 2 [创建默认群组] → 向左 → 泳道 1 {注册成功？}（标注：201 注册成功）
