# UML 活动图：成员关系流程（泳道图）

## 1. 图表结构
- **类型**：UML 活动图（Activity Diagram）/ 泳道图
- **布局**：横向 3 泳道，从左到右依次排列
- **泳道标题栏颜色**：
  - 请求方（前端）：蓝色
  - 后端服务：黄色
  - 目标方（前端/通知中心）：绿色
- **起止节点**：顶部实心黑圆（开始），底部实心黑圆（结束）

## 2. 泳道详情与流程

### 流程一：发送好友申请

#### 泳道 1：请求方（左侧）
- **节点序列**：
 1. 开始（实心圆）
 2. [搜索或找到目标用户]（矩形）
 3. [点击"加好友"，输入备注（可选）]（矩形）
 4. [点击发送]（矩形，调用 POST /api/friend-request）
 5. {成功？}（菱形判断）
    - N → [显示错误，如"已发送过申请"、"已是好友"]（矩形）
    - Y → [显示"好友申请已发送"]（矩形）
 6. 结束（实心圆）

#### 泳道 2：后端服务（中间）
- **节点序列**：
 1. {目标用户存在？}→ N → 404
 2. {已是好友？}（查 user_relations.is_friend）→ Y → 400
 3. {已有待处理申请？}（查 notifications status='pending'）→ Y → 400
 4. [向 friend_requests 和 notifications 插入记录（status='pending'）]（矩形）
 5. commit
 6. 结束（实心圆）

#### 泳道 3：目标方（右侧）
- **节点序列**：
 1. [通知中心轮询到新通知]（矩形）
 2. [渲染好友申请卡片，含发送者姓名、备注、"同意"/"拒绝"按钮]（矩形）
 3. 结束（实心圆）

### 流程二：处理好友申请（同意/拒绝）

#### 泳道 1：目标方（右侧）
- **节点序列**：
 1. 开始（实心圆）
 2. [在通知卡片上点击"同意"或"拒绝"]（矩形，调用 POST /api/notifications/{id}/approve 或 reject）
 3. [通知卡片变为"已处理"]（矩形）
 4. 结束（实心圆）

#### 泳道 2：后端服务（中间）
- **节点序列**（同意分支）：
 1. {通知存在且 status='pending'？}→ N → 404
 2. [设置 notifications.status='approved', is_read=1]（矩形）
 3. [向 user_relations 插入双向好友记录]（矩形，is_friend=1）
 4. [向 friends 插入双向记录（旧表兼容）]（矩形）
 5. [将双方互相加入对方的"私聊"聊天室]（矩形，如未在聊天室中）
 6. commit

- **节点序列**（拒绝分支）：
 1. [设置 notifications.status='rejected', is_read=1]（矩形）
 2. commit

### 流程三：删除好友

#### 泳道 1：请求方（左侧）
1. 开始（实心圆）
2. [在好友列表中右键点击好友，选择"删除好友"]（矩形）
3. {确认？}→ N → 结束
4. 调用 POST /api/friends/remove
5. 结束（实心圆）

#### 泳道 2：后端服务（中间）
1. {好友关系存在？}→ N → 404
2. [删除 user_relations 中双方好友标记（is_friend=0）]（矩形）
3. [删除 friends 中双向记录]（矩形）
4. commit

### 流程四：黑名单管理

#### 泳道 1：请求方（左侧）
1. 开始（实心圆）
2. [在用户列表中选择"拉黑"或"移出黑名单"]（矩形）
3. 调用 POST /api/blacklist/add 或 /remove
4. 结束（实心圆）

#### 泳道 2：后端服务（中间）
- **节点序列**（拉黑）：
 1. {目标用户存在？}→ N → 404
 2. {已是好友？}→ Y → [先解除好友关系（删除 friends 双向记录）]
 3. [设置 user_relations.is_blocked=1]（矩形）
 4. [向 blacklist 插入记录（旧表兼容）]（矩形）
 5. commit

- **节点序列**（移出黑名单）：
 1. [设置 user_relations.is_blocked=0]（矩形）
 2. [删除 blacklist 记录]（矩形）
 3. commit

## 3. 跨泳道连接线说明
- 泳道 1 [点击发送申请] → 向右 → 泳道 2 [接收并校验请求]
- 泳道 2 [插入通知] → 向右 → 泳道 3 [通知中心展示]
- 泳道 3 [同意/拒绝] → 向左 → 泳道 2 [处理审批]
- 泳道 1 [删除好友/拉黑] → 向右 → 泳道 2 [执行操作]
