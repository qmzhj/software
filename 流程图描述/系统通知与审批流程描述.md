# UML 活动图：系统通知与审批流程（泳道图）

## 1. 图表结构
- **类型**：UML 活动图（Activity Diagram）/ 泳道图
- **布局**：横向 3 泳道
- **泳道标题栏颜色**：
  - 申请人（前端）：蓝色
  - 通知服务：黄色
  - 审批人（通知中心）：绿色
- **起止节点**：顶部实心黑圆（开始），底部实心黑圆（结束）

## 2. 泳道详情与流程

### 流程一：申请与审批

#### 泳道 1：申请人（左侧）
- **节点序列**：
 1. 开始（实心圆）
 2. [触发申请（加好友/加入小组/聊天室邀请）]（矩形）
 3. [等待审批结果]（矩形）
 4. {结果}（菱形判断）
    - 同意 → [执行成功后续操作]
    - 拒绝 → [收到拒绝通知]
 5. 结束（实心圆）

#### 泳道 2：通知服务（中间）
- **节点序列**：
 1. 接收申请
 2. {校验通过？}（菱形判断，重复申请/目标存在/权限检查）
    - N → 返回错误
    - Y → 步骤 3
 3. [写入待审批通知，推送给审批人]（矩形）
 4. {审批决定}（菱形判断）
    - 同意 → [更新通知状态，执行后续操作（建立好友关系/加入小组/加入聊天室）]
    - 拒绝 → [更新通知状态]
 5. [向申请人推送审批结果]（矩形）
 6. 结束（实心圆）

#### 泳道 3：审批人（右侧）
- **节点序列**：
 1. [在通知中心看到待审批通知]（矩形）
 2. [点击"同意"或"拒绝"]（矩形）
 3. 结束（实心圆）

## 3. 跨泳道连接线说明
- 泳道 1 → 泳道 2 [发起申请]
- 泳道 2 → 泳道 3 [推送待审批通知]
- 泳道 3 → 泳道 2 [返回审批决定]
- 泳道 2 → 泳道 1 [推送审批结果]
