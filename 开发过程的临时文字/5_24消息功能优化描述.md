# 一段
1. 扩展消息发送功能，参考微信，在消息发送框添加一个"+"选项，用户点击后可以上传图片、文件、视频
    - 上传后图片在聊天框中显示缩略图，点击后在弹窗中显示原图
    - 文件显示文件名+大小，点击后显示是否下载确认弹框，确认后点击下载按钮后触发浏览器下载
    - 视频是支持预览，聊天框中显示视频缩略图（首帧截图）+ 播放按钮，点击后在弹窗中播放视频
    - 文件类型不限制,大小不超过500MB，前端 <input   accept="image/*,video/mp4,audio/mp3,audio/wav,.pdf,.doc,.docx,.xls,.xlsx,.zip,.rar,.txt">做一层友好提示，if filesize > 500 * 1024* 1024: return error 

2. 完善消息撤回功能，用户发送某条消息后，在两分钟内右键该条消息，会显示撤回选项
    - 现有的撤回接口用户无法调用，前端没有入口，补充右键入口
    - 撤回后消息在界面显示"xxx（撤回用户）撤回了一条消息"，私聊和聊天室撤回后显示同样文案
    - 在聊天室中，管理员或群主右键成员消息可以显示撤回选项，不限时，即管理员和群主可以随时撤回成员消息
    - 私聊消息和聊天室消息都支持撤回

3. 扩展消息功能，增加转发功能，在用户右键某条消息后，显示"多选"和"转发"选项
    - 转发选择界面:点击"逐条转发"或"合并转发"后出现一个选择界面，可以多选聊天室和成员进行消息转发，选择范围是所有聊天室和系统所有已注册用户，聊天室分一栏、用户列表分一栏
    - 参考微信，转发选项点击后显示转发选择界面，直接转发选中的一条消息
    - "多选"选项：参考微信，点击后可以勾选多条消息，并将聊天界面最下方的消息发送框替换为两个选项:"逐条转发"和"合并转发"
        - 参考微信，合并转发转发的是一个聊天记录包，用户点击后显示一个新界面，新界面展示一条条聊天记录，显示发送者名称和消息内容
        - 参考微信，逐条转发是直接把多条聊天记录转发到另一处聊天，发送者显示为转发者(不是被转发者)，直接多次调用发送消息逻辑来实现， 选择"聊天室"应该调群聊发送接口（POST /api/groups/{chatId}/send），选择"用户"应该调私聊接口（POST /api/send）
        - 有一个"取消"出口，点击后取消多选
    - 不支持直接合并转发图片/文件/视频，只支持逐条转发或单条转发图片/文件/视频，合并转发时，媒体消息显示为'[图片]'/'[文件]'/'[视频]' 占位文案，不可点击查看



# 二段
4. 完善好友通知功能，在成员详情界面（即）取消好友关系时会弹出确认框，确认后取消好友关系，双方好友关系解除，并自动向被取消掉好友发送一个通知"xxx已取消和你的好友关系"，通知出现在系统通知，与现有通知机制（group_messages 中 msg_type='system'）一致，即复用 announcements 表
5. 完善拉黑功能，点击拉黑后弹出简单的确认框，点击确认后会拉黑该用户，并向被拉黑用户发送一个通知"xxx已将你拉黑"，被拉黑者不能继续发送消息，不能查看对方信息，聊天历史保留，通知出现在系统通知，与现有通知机制（group_messages 中 msg_type='system'）一致，即复用 announcements 表
    - 被拉黑者可以在收到拉黑通知后再次尝试发消息，此时用户试图发送消息时前端会弹出提示“你已被此用户拉黑”
6. 扩展通知功能，每条通知添加已读未读标识，如果有未读通知，则在main侧边栏的通知选项中显示未读红点，announcements表需要增加 is_read 字段
    - 用户可以一键已读所有通知
    - 点击通知时标记已读
## 修复建议

1. main的通知栏在有未读通知时未显示红色小圆点
2. 将已读通知和未读通知分为两个栏目，原来的"一键已读"按钮移动到未读通知栏目中
3. 增加删除通知功能，删除是物理删除
    - 在已读通知栏目增加一键删除按钮，点击后删除全部已读通知
    - 右键一个通知后，弹出删除选项，点击确认后删除选中通知
4. 增加通知锁定功能，用户右键一个通知后，弹出锁定选项，点击确认后锁定选中通知，被锁定的通知无法被删除，announcements 表加 is_locked 列，用户只能锁定自己的通知。这个锁定是针对"防误删"的场景
5. 优化通知显示，每一条未读通知都显示一个"标记已读"按钮，点击后将该通知标记为已读，并自动移动到已读通知栏目

# 三段
- 点击视频聊天和语音通话按钮后
    - 如果是在聊天室内发起语音视频，则显示一个选择界面，可以多选聊天室成员邀请进入语音视频，选择范围是所有聊天室内成员
    - 如果是在私聊内发起语音视频，先检查双方是不是好友，若不是好友，则弹出"你不是该用户的好友，无法"则弹出“是否进行通话”提示框，确认后尝试进行通话，
- 尝试进行通话时
    - 如果是在聊天室内发起语音视频，则检查勾选成员的登录状态
        - 若所有勾选成员都不在登录状态，则弹出“所有成员均未登录”提示，用户点击确认后退回到聊天界面
        - 若有成员在登录状态，则进入通话界面
    - 如果是在私聊内发起语音视频
        - 若对方未在登录状态，则弹出“对方未在线”提示，用户点击确认后退回聊天界面
        - 若对方在登录状态，则弹出“是否进行通话”提示框，确认后尝试进行通话
- 通话权限
    - 为聊天室详情界面增加一个选项，用于选择来自该聊天室的语音通话邀请是否弹窗，默认选择"否"，系统创建的课程以及班级聊天室中，此选项强制为"是"
    - 一对一聊天的详情界面增加一个选项，同样用于选择来自该聊天的语音通话邀请是否弹窗，默认选择“否”
- 通话界面
    - 语音通话和视频通话使用同一个界面，界面中有打开麦克风按钮，挂断通话按钮，开启摄像头按钮
