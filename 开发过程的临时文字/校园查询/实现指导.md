### 1.2 添加 `_load_classes_from_json()` 函数

在 `_load_lessons_from_json()` 函数（约 line 190）之后添加：

```python
def _load_classes_from_json(filepath, conn):
    """
    从 class.json 加载班级数据，写入 classes / class_positions / class_stu 表。
    class_id 直接用 class_name。
    """
    try:
        if not os.path.exists(filepath):
            print(f"警告: 文件 {filepath} 不存在")
            return
        with open(filepath, 'r', encoding='utf-8') as f:
            data = json.load(f)
        c = conn.cursor()
        for cls in data:
            class_id = cls.get('class_name', '')  # class_name 作为 class_id
            grade = cls.get('grade', '')
            major = cls.get('major', '')
            department = cls.get('department', '')
            # level 判断：班级名含"级"则为年级群，否则为班级群
            level = 'grade' if '级' in class_id else 'class'

            # 插入 classes 表
            c.execute('INSERT OR IGNORE INTO classes VALUES (?,?,?,?,?,?)',
                      (class_id, class_id, grade, major, department, level))

            # 插入 class_positions（班干部）
            cadre = cls.get('class_cadre', {})
            for position_name, uid in cadre.items():
                c.execute('INSERT OR IGNORE INTO class_positions (class_id, uid, position_name) VALUES (?,?,?)',
                          (class_id, uid, position_name))

            # 插入 class_stu（班级成员）
            for uid in cls.get('class_member', []):
                c.execute('INSERT OR IGNORE INTO class_stu (class_id, uid) VALUES (?,?)',
                          (class_id, uid))

        conn.commit()
        print(f"已从 {filepath} 导入班级数据")
    except Exception as e:
        print(f"加载班级数据时出错: {e}")
```

关键设计点：

| 项目 | 说明 |
|------|------|
| `class_id` | 直接用 `class_name`，不额外生成 hash |
| `level` | 通过"级"关键字判断：`"2024级计算机学院"` → `'grade'`，`"网工一班"` → `'class'` |
| 重复导入 | `INSERT OR IGNORE` 防止重复写入（服务重启时不会重复插入） |
| `class_cadre` | JSON 中的键值对直接映射到 `class_positions` 的 `position_name` 和 `uid` |

## 二、赛事相关数据表

赛事小组表（`events_groups`、`events_groups_members`）用于支持赛事组队功能，同时也作为用户搜索中"按赛事"搜索的数据来源。

### 2.1 在 `init_db()` 中添加建表语句

### 2.2 添加 `_load_events_from_json()` 函数

在 `_load_classes_from_json()` 之后添加：

```python
def _load_events_from_json(filepath, conn):
    """
    从 events.json 加载赛事数据，插入 events 表。
    同时为每个赛事创建一些示例小组，方便演示。
    """
    try:
        if not os.path.exists(filepath):
            print(f"警告: 文件 {filepath} 不存在")
            return
        with open(filepath, 'r', encoding='utf-8') as f:
            data = json.load(f)
        c = conn.cursor()
        for ev in data:
            # 插入 events 表（id 自动递增，传 None 让 SQLite 自动分配）
            c.execute('INSERT INTO events (id, name, type, start_time, end_time, location, target, organizer, description) VALUES (?,?,?,?,?,?,?,?,?)',
                      (None,
                       ev.get('name', ''),
                       ev.get('type', ''),
                       ev.get('start_time', ''),
                       ev.get('end_time', ''),
                       ev.get('location', ''),
                       ev.get('target', ''),
                       ev.get('organizer', ''),
                       ev.get('description', '')))
            event_id = c.lastrowid  # 获取刚插入的赛事 id

        conn.commit()
        print(f"已从 {filepath} 导入赛事数据")
    except Exception as e:
        print(f"加载赛事数据时出错: {e}")
```

> **注意**：`INSERT INTO events ... VALUES (None, ...)` 中 `id` 传 `None`，让 SQLite 的 `AUTOINCREMENT` 自动分配 ID。这与原 `_seed_data()` 中手动指定 ID（`1, '秋季运动会'`）的方式不同，避免与后续管理员手动发布赛事的自增 ID 冲突。
