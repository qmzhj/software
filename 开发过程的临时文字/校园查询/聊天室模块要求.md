# 聊天室模块要求说明

## 一、概述

聊天室（Chat Room）是本平台的核心通讯单元，对应数据库 `groups_chat` 表。聊天室归属于群组容器（`user_groups`），通过 `user_group_chats` 建立关联。一个群组可包含多个聊天室，一个聊天室可被多个群组引用。

---

## 二、聊天室分类

### 2.1 四种聊天室类型

根据 `creator` + `category` 区分：

| 聊天室类型 | `creator` | `category` | 创建方式 |
|-----------|----------|-----------|---------|
| 普通聊天室 | 用户 uid | 自定义（如"办公群"） | 用户在群组内创建 |
| 课程聊天室 | `system` | `课程` | 系统初始化自动创建 |
| 班级聊天室 | `system` | `班级` | 系统初始化自动创建（两栏式展示待实现） |
| 赛事聊天室 | `system` | `赛事` | 赛事发布时自动创建 |

### 2.2 标识规则

- 课程聊天室：`group_id` = `'chat_' + lesson_id`
- 班级聊天室：`group_id` = `'chat_class_' + class_id`（两栏式展示待实现）
- 赛事聊天室：`group_id` = `'chat_event_' + event_id`
- 普通聊天室：`group_id` = `secrets.token_hex(8)`

---

## 三、聊天室自动创建

### 3.1 课程聊天室

**触发时机**：`_seed_data()` 中，导入 lesson 数据后立即创建。

**逻辑**：
1. 遍历 `lesson` 表所有课程
2. 每门课程创建 `groups_chat` 记录：`creator='system'`, `category='课程'`
3. 从 `lesson_stu` 查出所有学生，加入为 `member`
4. 从 `lesson.teacher_uid` 查出授课教师，加入为 `admin`
5. 仅首次初始化执行一次

### 3.2 班级聊天室

初始化时遍历 `classes` 表，为每个班级创建聊天室：
- `group_id` = `'chat_class_' + class_id`
- `creator='system'`, `category='班级'`
- 从 `class_stu` 查出所有学生，加入为 `member`
- 从 `class_positions` 查出班长、兼班、兼助、辅导员等职位，加入为 `admin`

**年级聊天室**：若 class_id 含"级"关键字（如"2024级计算机学院"），`level='grade'`，同样创建聊天室，班级成员即该年级所有学生。年级聊天室不设 `admin`。

### 3.3 赛事聊天室

**触发时机**：赛事发布时自动创建。种子数据中的赛事在 `_seed_data()` 中创建，管理员通过表单发布的赛事在提交时创建。

**逻辑**：
1. 创建 `groups_chat` 记录：`creator='system'`, `category='赛事'`
2. 赛事发布者（`events.creator_uid`）自动设为 `admin`
3. 用户加入赛事小组（`events_groups_members`）时，自动将该用户加入赛事聊天室为 `member`
4. 用户退出赛事小组时，自动从赛事聊天室移除

**数据要求**：
- `events` 表需新增字段 `creator_uid TEXT`，记录赛事发布者的 uid
- 种子赛事在 `_seed_data` 中指定 `creator_uid`

## 四、聊天室详情界面

四种聊天室类型的详情界面采用不同的成员展示和操作逻辑。

### 4.1 普通聊天室

- 成员平铺展示
- 身份标识：`🔑群主`（`role='admin'`）、`🛡️管理员`（`role='manager'`）
- 职位标签：不显示
- 群主可操作：**设为管理员** / **取消管理** / **踢出**

### 4.2 课程聊天室

**成员展示**：
- 成员平铺展示，不分区
- 身份标识：群主（教师）显示 `👑教师` 替代 `🔑群主`，管理员显示 `🛡️管理员`
- 职位标签（仅限课程相关）：`📖课代表`（`lesson_positions`）
- 教师和课代表显示在成员列表顶部
- 其他同学无标签
- 不显示班级/年级等非课程职位标签

**管理员操作栏**：
- 以 **"设为课代表"** 按钮替换 **"设为管理员"** 按钮，即不显示"设为管理员/取消管理"，改为"设为课代表/取消课代表"
- 点击后调用 `POST /api/lesson-positions/set`，自动创建 `lesson_positions` 表项（`lesson_id`, `uid`, `position_name='课代表'`）
- 取消课代表调用 `POST /api/lesson-positions/unset`，删除对应表项
- `lesson_positions` 数据由教师在聊天室详情界面自行设置，不从 JSON 加载
- 课代表只记录在 `lesson_positions` 中，不修改 `group_members.role`

**角色设定**：
- `lesson.teacher_uid` 的教师自动设为 `group_members.role='admin'`
- 课代表 `group_members.role` 保持 `'member'`

### 4.3 班级聊天室

> 两栏式展示（班干部栏 + 班级成员栏）待实现

**成员展示**——分两个栏目：

| 栏目 | 包含人员 | 身份标识 |
|------|---------|---------|
| 班干部 | `class_positions` 中有职位的学生 | `🔑群主`（设为admin的职位）+ 具体职位名 |
| 班级成员 | `class_stu` 中其余普通同学 | 无 |

**职位标签规则**：
- 仅显示该班级自己的职位，不展示年级级或其他班级的标签
- 不显示"设为管理员"或"设为课代表"按钮

**角色设定**：
- 创建时从 `class_positions` 中查询 `兼班`、`兼助`、`班长`，将 `group_members.role` 设为 `admin`

### 4.4 赛事聊天室

**成员展示**：
- 与普通聊天室类似，成员平铺展示
- 身份标识：`🏆负责人`（`role='admin'`，替代 `🔑群主`）、`🛡️管理员`
- 职位标签：不显示

**成员来源**：
- 所有 `events_groups_members` 中参与该赛事的用户自动加入
- 赛事发布者设为 `group_members.role='admin'`

**权限**：
- 负责人可操作：**设为管理员** / **取消管理** / **踢出**（与普通聊天室相同，仅标签从"群主"改为"负责人"）

### 4.5 职位标签显示范围总结

| 聊天室类型 | 通用角色标签 | 职位标签 | 职位标签来源 |
|-----------|-------------|---------|------------|
| 普通聊天室 | 🔑群主/🛡️管理员 | 不显示 | — |
| 课程聊天室 | 👑教师(替代🔑群主)/🛡️管理员 | 📖课代表 | `lesson_positions`、`lesson.teacher_uid` |
| 班级聊天室 | 🔑群主/🛡️管理员 | 该班级班干部职位 | `class_positions`（仅限当前class_id） |
| 赛事聊天室 | 🏆负责人(替代🔑群主)/🛡️管理员 | 不显示 | — |

## 五、群组容器关联

### 5.1 系统群组

每个用户注册时 `ensure_default_groups(uid)` 自动建立：

| 群组名称 | `category` | 包含内容 |
|----------|-----------|----------|
| 即时聊天 | `即时聊天` | 非好友的全校用户搜索和私聊入口 |
| 私聊 | `私聊` | 好友私聊入口 |
| 课程和班级 | `课程和班级` | 该用户参与的课程聊天室 + 班级/年级聊天室引用 |
| 赛事 | `赛事` | 该用户参与/负责的赛事聊天室引用 |

### 5.2 "未分类"虚拟群组

用户加入但未被任何显式群组引用的聊天室，自动出现在"未分类"中，不存储在 `user_groups` 表。

### 5.3 ensure_default_groups 职责

仅负责：
1. 创建/检查系统群组（即时聊天、私聊、课程和班级、赛事）
2. 将课程聊天室通过 `user_group_chats` 关联到"课程和班级"群组
3. 将班级/年级聊天室通过 `user_group_chats` 关联到"课程和班级"群组
4. 将赛事聊天室通过 `user_group_chats` 关联到"赛事"群组

不负责：
- ❌ 创建聊天室（聊天室在 `_seed_data` 或赛事发布时已建好）
- ❌ 将用户加入聊天室（已在初始化或加入小组时加入）

## 六、API 端点

### 6.1 现有端点

| 方法 | 路由 | 说明 |
|------|------|------|
| GET | `/api/groups/<id>/detail` | 聊天室详情（成员列表） |
| POST | `/api/groups` | 创建聊天室 |
| POST | `/api/groups/<id>/send` | 发送消息 |
| POST | `/api/groups/<id>/kick` | 踢出成员 |
| POST | `/api/groups/<id>/admin` | 设置/取消管理员 |
| POST | `/api/groups/<id>/dissolve` | 解散聊天室 |

### 6.2 新增端点（课代表管理）

| 方法 | 路由 | 说明 |
|------|------|------|
| POST | `/api/lesson-positions/set` | 设为课代表，创建 `lesson_positions` 记录 |
| POST | `/api/lesson-positions/unset` | 取消课代表，删除 `lesson_positions` 记录 |

## 七、前端改动点

### 7.1 聊天室详情弹窗

根据聊天室类型区分渲染逻辑：

```
chat.detail → 判断 chat['creator'] 和 chat['category']
  ├─ creator='system' AND category='课程' → 课程聊天室渲染
  ├─ creator='system' AND category='赛事' → 赛事聊天室渲染
  ├─ creator='system' AND category='班级' → 班级聊天室渲染（两栏式待实现）
  └─ 其他 → 普通聊天室渲染
```

**职位标签过滤规则**（后端 `chat_room_detail` 实现）：
- 课程聊天室：仅查询 `lesson_positions` 和 `lesson.teacher_uid`，不查 `class_positions`
- 班级聊天室：仅查询 `class_positions` 且 `class_id` 匹配当前聊天室，不查 `lesson_positions`
- 普通/赛事聊天室：不查询任何职位表

### 7.2 课程聊天室详情

- 成员列表：平铺，群主（教师）显示 `👑教师`，课代表显示 `📖课代表`，管理员显示 `🛡️管理员`
- 操作栏：群主看到的是"设为课代表"而非"设为管理员"
- 不显示班级/年级等非课程职位标签

### 7.3 班级聊天室详情（两栏式待实现）

- 成员列表分两栏："班干部"栏和"班级成员"栏
- 班干部显示具体职位名称（班长/团支书/兼班/兼助...）及 `🔑群主` 标识
- 仅显示该班级自己的职位标签
- 无管理员操作按钮

### 7.4 赛事聊天室详情

- 与普通聊天室渲染逻辑相同，成员平铺展示
- 身份标识：`🏆负责人`（替代 `🔑群主`）、`🛡️管理员`
- 操作按钮不变：设为管理员/取消管理/踢出

## 八、数据表

### groups_chat

```
group_id   TEXT PRIMARY KEY
name       TEXT
creator    TEXT           -- 用户 uid 或 'system'
created_at REAL
group_type TEXT DEFAULT 'custom'  -- 'custom' | 'system'
category   TEXT DEFAULT '办公群'  -- '课程' | '班级' | '赛事' | '办公群' | 自定义
```

### events（新增 creator_uid 字段）

```
id          INTEGER PRIMARY KEY AUTOINCREMENT
name        TEXT
type        TEXT
start_time  TEXT
end_time    TEXT
location    TEXT
target      TEXT
organizer   TEXT               -- 组织单位（如"院团委竞赛部"）
description TEXT
creator_uid TEXT               -- 发布者 uid，关联 users.uid，用于设定赛事聊天室管理员
```

### lesson_positions

```
id            INTEGER PRIMARY KEY AUTOINCREMENT
lesson_id     TEXT NOT NULL     -- 关联 lesson.lesson_id
uid           TEXT NOT NULL     -- 用户 uid
position_name TEXT NOT NULL     -- 职位名称（如"课代表"）
FOREIGN KEY (lesson_id) REFERENCES lesson(lesson_id)
FOREIGN KEY (uid) REFERENCES users(uid)
```
