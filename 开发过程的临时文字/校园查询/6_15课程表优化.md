# 课程表优化

## 1. 扩充庞雄文的课程数据

在 `lessons.json` 中为教师庞雄文（TE2023009）追加若干课程，**课程名同样是”软件工程”**，但：
- 上课时间各不相同（不同的 weekday + period）
- 每门课的学生名单（stu_uids）互不相同
- 目的是演示同一教师教授多门同名课程时，课程表能正确区分显示，并为后续聊天室命名优化提供素材

当前已有一门”软件工程”（周二7-8节），建议追加：
- 软件工程（周三5-6节）— 学生为另一批账号
- 软件工程（周四3-4节）— 学生为再一批账号

## 2. 优化课程聊天室命名规则

### 现状

`_create_course_chat_rooms()` 创建聊天室时，名字固定为 `lesson_name + '聊天室'`。例如庞雄文的两门课分别叫”软件工程聊天室”和”软工实验聊天室”。

如果庞雄文有多个名为”软件工程”的课程（在不同时段），它们在聊天室列表里都会显示为”软件工程聊天室”，无法区分。

### 改动

将聊天室命名规则改为 `上课星期 + 上课节次 + 课程名`，例如：
- “软件工程”（周二7-8节）→ “周二78软件工程”
- “软件工程”（周三5-6节）→ “周三56软件工程”
- “软工实验”（周五9-10节）→ “周五910软工实验”

### 涉及代码

`app.py` 中 `_create_course_chat_rooms()` 函数（约第 419 行），将：

```python
# 旧
chat_name = lesson_name + '聊天室'

# 新
chat_name = schedule_weekday + schedule_period.replace('-', '') + lesson_name
```

其中 `schedule_weekday` 从 `lesson` 表的字符串（如”星期二”）截取前一个字（”周二”）更简洁。教师可通过聊天室名快速定位到具体的课程时段。
