# 用户查询模块实现指导

## 概述

基于 `5_31校园查询初步设计.md` 中"用户搜索"章节的设计，实现五维筛选搜索功能。用户可通过学号/姓名、课程、班级、身份、赛事五个条件组合搜索其他用户，搜索结果附带身份标签。

---

## 步骤一：后端搜索 API

### 修改位置

`app.py` — 新增路由（在现有搜索路由附近）。

### API 规格

```
GET /api/search/users?name_or_id=张三&course=软件工程&class=网工一班&position=班长&event_id=1
```

所有参数可选，非空参数做 AND 查询。

| 参数 | 类型 | 说明 | 查询逻辑 |
|------|------|------|---------|
| `name_or_id` | string | 学号或姓名 | `users.uid` 或 `users.name` LIKE 模糊匹配 |
| `course` | string | 课程名 | 通过 `lesson_stu` + `lesson` 找到上该课程的用户 |
| `class` | string | 班级名 | 通过 `class_stu` + `classes` 找到该班级的用户 |
| `position` | string | 职位名 | 通过 `class_positions` / `lesson_positions` 找到有该职位的用户 |
| `event_id` | int | 赛事 ID | 通过 `events_groups` + `events_groups_members` 找参与该赛事的用户 |

### 返回格式

```json
[
    {
        "uid": "202421326578",
        "name": "张三",
        "role": "student",
        "tags": ["班长", "课代表-数据结构"]
    }
]
```

`tags` 数组包含该用户在所有班级/课程中的职位，以及参与的赛事标签（`"参赛-{赛事名}"`）。

### 实现方案

使用 SQL 的 INTERSECT 实现 AND 组合，或逐层过滤：

**方案：逐层过滤（推荐）**

从 `users` 表开始，每有一个非空参数就 JOIN 对应表做过滤：

```python
@app.route('/api/search/users')
@token_required
def search_users():
    name_or_id = request.args.get('name_or_id', '').strip()
    course = request.args.get('course', '').strip()
    class_name = request.args.get('class', '').strip()
    position = request.args.get('position', '').strip()
    event_id = request.args.get('event_id', '').strip()

    conn = get_db()
    query = 'SELECT DISTINCT u.uid, u.name, u.role FROM users u WHERE 1=1'
    params = []

    if name_or_id:
        query += ' AND (u.uid LIKE ? OR u.name LIKE ?)'
        params.append(f'%{name_or_id}%')
        params.append(f'%{name_or_id}%')

    if course:
        query += ' AND u.uid IN (SELECT stu_uid FROM lesson_stu ls JOIN lesson l ON ls.lesson_id=l.lesson_id WHERE l.lesson_name LIKE ?)'
        params.append(f'%{course}%')

    if class_name:
        query += ' AND u.uid IN (SELECT uid FROM class_stu cs JOIN classes c ON cs.class_id=c.class_id WHERE c.class_name LIKE ?)'
        params.append(f'%{class_name}%')

    if position:
        query += ''' AND u.uid IN (
            SELECT uid FROM class_positions WHERE position_name LIKE ?
            UNION
            SELECT uid FROM lesson_positions WHERE position_name LIKE ?
        )'''
        params.append(f'%{position}%')
        params.append(f'%{position}%')

    if event_id:
        query += ''' AND u.uid IN (
            SELECT member_uid FROM events_groups_members egm
            JOIN events_groups eg ON egm.group_id=eg.id
            WHERE eg.event_id=?
        )'''
        params.append(event_id)

    users = conn.execute(query, params).fetchall()
```

**标签组装**：查询到用户后，为每个用户查询其所有身份标签：

```python
result = []
for u in users:
    tags = []
    # 班干部职位
    cp_rows = conn.execute('''SELECT DISTINCT cp.position_name, c.class_name
                               FROM class_positions cp
                               JOIN class_stu cs ON cp.class_id=cs.class_id AND cp.uid=cs.uid
                               JOIN classes c ON cp.class_id=c.class_id
                               WHERE cs.uid=?''', (u['uid'],)).fetchall()
    for r in cp_rows:
        tags.append(f"{r['class_name']} {r['position_name']}")

    # 课代表职位
    lp_rows = conn.execute('''SELECT DISTINCT lp.position_name, l.lesson_name
                               FROM lesson_positions lp
                               JOIN lesson l ON lp.lesson_id=l.lesson_id
                               WHERE lp.uid=?''', (u['uid'],)).fetchall()
    for r in lp_rows:
        tags.append(f"{r['lesson_name']} {r['position_name']}")

    # 参赛标签
    ev_rows = conn.execute('''SELECT DISTINCT e.name
                               FROM events_groups_members egm
                               JOIN events_groups eg ON egm.group_id=eg.id
                               JOIN events e ON eg.event_id=e.id
                               WHERE egm.member_uid=?''', (u['uid'],)).fetchall()
    for r in ev_rows:
        tags.append(f"参赛-{r['name']}")

    result.append({
        'uid': u['uid'],
        'name': u['name'],
        'role': u['role'],
        'tags': tags
    })

return jsonify(result)
```

## 步骤二：前端搜索界面

### 修改位置

`static/query.html` — 替换或改造现有搜索功能。

### UI 布局

五个筛选框横向一字排开：

```
[学号/姓名:________] [课程:▾__________] [班级:▾__________] [身份:▾__________] [赛事:▾__________]  [🔍 搜索]
```

| 筛选框 | 控件类型 | 数据来源 |
|--------|---------|---------|
| 学号/姓名 | 文本输入框 | — |
| 课程 | 下拉菜单（可选） | `GET /api/search/options?type=courses` 或直接硬编码课程列表 |
| 班级 | 下拉菜单（可选） | `GET /api/search/options?type=classes` 或直接硬编码班级列表 |
| 身份 | 下拉菜单（可选） | 预设职位列表：班长、团支书、学委、组委、心委、课代表... |
| 赛事 | 下拉菜单（可选） | `GET /api/events` |

### 数据源 API（新增，供下拉菜单使用）

```python
@app.route('/api/search/options')
@token_required
def search_options():
    type_ = request.args.get('type', '')
    conn = get_db()
    if type_ == 'courses':
        rows = conn.execute('SELECT DISTINCT lesson_name FROM lesson ORDER BY lesson_name').fetchall()
        return jsonify([r['lesson_name'] for r in rows])
    elif type_ == 'classes':
        rows = conn.execute('SELECT DISTINCT class_name FROM classes ORDER BY class_name').fetchall()
        return jsonify([r['class_name'] for r in rows])
    return jsonify([])
```

### 搜索逻辑

前端从五个筛选框取值，拼接查询参数调用后端 API：

```javascript
async function searchUsers() {
    const params = new URLSearchParams();
    const nameVal = document.getElementById('searchName').value.trim();
    const courseVal = document.getElementById('searchCourse').value;
    const classVal = document.getElementById('searchClass').value;
    const posVal = document.getElementById('searchPosition').value;
    const eventVal = document.getElementById('searchEvent').value;

    if (nameVal) params.set('name_or_id', nameVal);
    if (courseVal) params.set('course', courseVal);
    if (classVal) params.set('class', classVal);
    if (posVal) params.set('position', posVal);
    if (eventVal) params.set('event_id', eventVal);

    const url = '/api/search/users?' + params.toString();
    const results = await api(url);
    renderSearchResults(results);
}
```

### 结果渲染

搜索结果以用户卡片列表展示，每个用户显示：

```
[头像] 姓名 (学号)
       角色: 学生
       标签: [班长] [课代表-数据结构] [参赛-ROBOTAC]
```

标签以徽标（badge）形式展示：

```html
<span style="background:#eef2ff;color:#4f46e5;padding:2px 8px;border-radius:10px;font-size:12px;">班长</span>
```

### 标签控制

搜索结果始终返回用户的所有标签，但前端**按所填筛选条件控制展示**：

| 填写的筛选条件 | 前端展示的标签 |
|--------------|--------------|
| 仅填学号/姓名 | 不展示任何标签（干净视图） |
| 填了课程 | 展示课代表标签 |
| 填了班级 | 展示班干部标签 |
| 填了身份 | 展示匹配的职位标签 |
| 填了赛事 | 展示参赛标签 |
| 同时填了多个 | 同时展示各类标签 |

实现方式：为每个 tag 附加其来源类型（`class`/`lesson`/`event`），前端根据填写的筛选条件过滤展示。

## 步骤三：搜索结果交互

### 点击用户

点击搜索结果中的用户，弹出用户信息面板（复用现有 `showMemberInfo` 逻辑），显示：
- 头像、姓名、学号
- 角色（学生/教师/管理员）
- 个人简介
- 身份标签列表
- 操作按钮：**发消息** / **加好友**

### 发消息

点击"发消息"跳转到即时聊天或私聊界面：
- 若已是好友 → 打开私聊对话
- 若还不是好友 → 发送好友请求

### 搜索状态保持

搜索条件和结果应在切换页面后保持（使用 `sessionStorage` 或 URL 参数）。

## 执行顺序

```
步骤一 (后端 API) → 步骤二 (前端界面) → 步骤三 (交互优化)
```

步骤一必须先完成，步骤二和步骤三可同步进行。步骤一中的 `GET /api/search/options` 可在步骤二中按需添加。
