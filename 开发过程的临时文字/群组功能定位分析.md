# 群组功能定位分析

## 一、群组的本质

群组（Group）是**用户个人的聊天管理工具**，而非一个"多人空间"。

类比手机桌面上的"文件夹"——你把应用拖进文件夹里分类，方便自己找，但这个文件夹只存在于你的手机上，不会出现在别人的手机上。

### 群组的定位

| 对比项 | 群组 (Group) | 聊天室 (Chat Room) |
|--------|-------------|-------------------|
| 本质 | 管理工具/容器 | 实际聊天空间 |
| 可见性 | 仅创建者可见 | 所有成员可见 |
| 参与者 | 只有自己（私有） | 多人共同参与 |
| 用途 | 分类整理聊天入口 | 发送消息、交流讨论 |

## 二、群组中管理的内容

一个群组可以收纳以下两类内容：

### 1. 聊天室（Chat Room）
- 将已有的聊天室（课程聊天室、自定义聊天室等）添加到群组中
- 用户可以通过群组快速进入这些聊天室
- 示例：建立一个"学习群组"，把所有课程聊天室放进去

### 2. 私聊联系人（Private Chat Contact）
- 将经常私聊的好友添加到群组中
- 在群组中可以快速发起与该联系人的私聊
- 示例：建立一个"项目组"群组，把项目合作的同学放进去

## 三、群组页面的展示

### 群组列表页（一级页面）
```
📁 学习    · 5 个聊天室 · 3 个联系人
📁 项目A   · 2 个聊天室 · 6 个联系人
📁 兴趣    · 1 个聊天室 · 0 个联系人
```

- 只显示当前用户自己创建的群组
- 系统群组（课程、即时聊天、私聊）是预设的公共群组，所有人都有

### 群组详情页（二级页面）

进入群组后，应清晰分为两部分：

```
👤 联系人（3）
  - 张三 → 点击发起私聊
  - 李四 → 点击发起私聊
  - 王五 → 点击发起私聊

💬 聊天室（5）
  - 高等数学聊天室 → 点击进入聊天
  - 软件工程聊天室 → 点击进入聊天
  - 数据结构聊天室 → 点击进入聊天
```

#### 联系人
- 显示用户添加到此群组的私聊联系人列表
- 点击联系人的操作：**发起与该联系人的私聊**
- 联系人的来源：从好友列表中选择加入群组

#### 聊天室
- 显示用户添加到此群组的聊天室列表
- 点击聊天室的操作：**进入该聊天室**

## 四、群组的操作

| 操作 | 说明 |
|------|------|
| 新建群组 | 创建一个自定义群组，填写名称和分类 |
| 重命名 | 修改群组名称 |
| 删除群组 | 删除群组（仅删除容器，不影响聊天室和好友关系） |
| 添加聊天室 | 从已有的聊天室列表中选择加入群组 |
| 移除聊天室 | 从群组中移除某个聊天室 |
| 添加联系人 | 从好友列表中选择联系人加入群组 |
| 移除联系人 | 从群组中移除某个联系人 |

## 五、系统预设群组

系统预设群组是自动创建的，不可删除：

| 群组 | 用途 |
|------|------|
| 课程 | 自动包含当前用户的所有课程聊天室 |
| 即时聊天 | 自动包含好友列表中的联系人（方便发起私聊） |
| 私聊 | 自动包含好友列表中的联系人（好友关系的私聊） |

系统群组和自定义群组在界面上用`系统`标签区分。

## 六、关键设计原则

1. **群组是私有的**：一个用户创建的群组，其他用户完全看不到
2. **群组是轻量的**：群组本身不包含消息、权限、角色等复杂概念
3. **群组是组织工具**：目的是让用户更快地找到想去的聊天室或想私聊的人
4. **删除群组不级联删除**：删除群组只是删除这个容器，里面的聊天室和好友关系不受影响


# 备注
你的理解很正确，我发现一个问题，当用户所在的某个聊天室没有在该用户的任何群组时，那么它就不会被该用户看到，为了解决这个问题，系统自动创建一个内容为纯聊天室的群组，用于存放没有被群组引用过的聊天室
