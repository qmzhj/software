# 一段
1. 优化群组功能，用用户在群组页面手动创建的自定义群组不出现在其他用户的群组列表中，即：一个用户建立群组时，另一个用户不会受到影响，（系统自动创建的「课程」「即时聊天」「私聊」群组不受影响）,总体的思想是：群组的目的是方便用户管理和组织聊天室和聊天，群组是管理工具，真正进行聊天的是聊天室和一对一聊天
2. 继续优化聊天室功能，目前建立聊天室后选中的成员都会直接被拉进聊天室中，修改这个逻辑，点击建立聊天室后会给所有勾选的的聊天室成员发送一条聊天室进入邀请通知，被邀请用户点击同意后才会进入聊天室
3. 目前普通聊天室成员的聊天界面一直显示“加载中”，无法看到聊天内容
4. 将加好友按钮转移到成员信息界面中

# 二段
1. 实现将聊天和成员移出群组功能：在群组内的侧边栏中添加“多选按钮”，点击后可以勾选多个聊天室和成员，一键将他们移出本群组，成员被移出群组后，只是从本群组联系人列表消失，不会影响到其它，只是解除关联（user_group_chats 和 user_group_members 中删除），不影响聊天室本身和好友关系
2. 合并“添加成员”和“关联聊天室”按钮为“添加聊天”按钮，点击后展示类似创建群组时的界面，可以勾选本群组外的、自己参与的所有聊天室，可勾选本群组外的所有联系人
3. "添加聊天"弹窗中，聊天室和好友分两个区域

# 三段
1. 在群组内的侧边栏中右键聊天室后，会显示两个选项：1.详情；2.移出本群组，用户点击详情后会显示 chatDetailModal，用户点击移出本群组并确认后会将该聊天室移出本群组
2. 在群组内的侧边栏中右键成员后，会显示两个选项：1.详情；2.移出本群组，用户点击详情后会显示该成员的信息详情页，用户点击移出本群组并确认后会将该成员移出本群组
