## 关键设计亮点

**通知系统数据库设计**（`数据表合并建议_user_relations.md`）：
- 受 IP 报文 Protocol 字段 + Payload 的设计启发
- 将三张分散的通知表合并为单表 `notifications`，通过 `type` 字段做多路分发
- 各类型专有数据统一存入 `extra` JSON 字段，避免表结构膨胀
- 消除前端 `fr_`/`ci_`/`sys_` 前缀解析，统一为数字 ID + type 判断
