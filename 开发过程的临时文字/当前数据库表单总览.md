# 数据库合并方案

两个数据表合并方案详见：[数据表合并建议_user_relations.md](./数据表合并建议_user_relations.md)

1. **user_relations 表合并**：friends + blacklist + call_preferences → user_relations（好友/黑名单/通话权限合一）
2. **notifications 表合并**：friend_requests + chat_invites + announcements（通知部分）→ notifications（统一通知表）



# 当前数据库表单总览

共 20 张表（含通过 `ALTER TABLE` 添加的列），按功能分组如下。

---

## 1. 认证与用户

### users
用户账户信息。
```sql
uid TEXT PRIMARY KEY, name TEXT, password TEXT, role TEXT,
locked INTEGER, unlock_time TEXT, login_fails INTEGER,
registed INTEGER, phone TEXT,
description TEXT DEFAULT ''   -- 后加
```

---

## 2. 消息

### messages
一对一私聊消息。
```sql
id INTEGER PRIMARY KEY AUTOINCREMENT,
sender TEXT, receiver TEXT, content TEXT,
msg_type TEXT DEFAULT 'text',      -- text / image / video / file / system
file_path TEXT, file_name TEXT, file_size INTEGER,
status TEXT DEFAULT 'sent', timestamp REAL,
revoked INTEGER DEFAULT 0
```

### group_messages
聊天室群聊消息（结构同 `messages`）。
```sql
id INTEGER PRIMARY KEY AUTOINCREMENT,
group_id TEXT, sender TEXT, content TEXT,
msg_type TEXT DEFAULT 'text',
file_path TEXT, file_name TEXT, file_size INTEGER,
status TEXT DEFAULT 'sent', timestamp REAL,
revoked INTEGER DEFAULT 0
```

---

## 3. 群组容器系统

### user_groups
群组容器（聊天室的集合）。
```sql
group_id TEXT PRIMARY KEY, name TEXT, creator TEXT, created_at REAL,
group_type TEXT DEFAULT 'custom',   -- custom / system
category TEXT DEFAULT '办公群'       -- 即时聊天 / 私聊 / 课程 / 自定义 / ...
```

### user_group_members
群组容器-成员关联。
```sql
group_id TEXT, uid TEXT, added_at REAL,
PRIMARY KEY (group_id, uid)
```

### user_group_chats
群组容器-聊天室关联。
```sql
group_id TEXT, chat_id TEXT, chat_name TEXT,
PRIMARY KEY (group_id, chat_id)
```

---

## 4. 聊天室

### groups_chat
聊天室（群聊房间）。
```sql
group_id TEXT PRIMARY KEY, name TEXT, creator TEXT,
created_at REAL, group_type TEXT DEFAULT 'custom',
category TEXT DEFAULT '办公群'
```

### group_members
聊天室成员（含通话权限）。
```sql
group_id TEXT, uid TEXT, role TEXT DEFAULT 'member',  -- member / manager / admin
joined_at REAL,
call_notify INTEGER DEFAULT 0,       -- 后加（通话权限开关）
PRIMARY KEY (group_id, uid)
```

### chat_invites
聊天室邀请记录。
```sql
id INTEGER PRIMARY KEY AUTOINCREMENT,
chat_id TEXT, chat_name TEXT, from_uid TEXT, to_uid TEXT,
status TEXT DEFAULT 'pending', created_at REAL,
is_read INTEGER DEFAULT 0            -- 后加（通知已读）
```

---

## 5. 好友 / 黑名单 / 权限

### friends
好友关系（单向）。
```sql
uid TEXT, friend_uid TEXT, created_at REAL,
PRIMARY KEY (uid, friend_uid)
```

### friend_requests
好友申请表。
```sql
id INTEGER PRIMARY KEY AUTOINCREMENT,
from_uid TEXT, to_uid TEXT, message TEXT,
status TEXT DEFAULT 'pending', created_at REAL,
is_read INTEGER DEFAULT 0            -- 后加（通知已读）
```

### blacklist
黑名单（单向拉黑）。
```sql
uid TEXT, blocked_uid TEXT,
PRIMARY KEY (uid, blocked_uid)
```

### call_preferences
私聊通话权限（per-user per-target）。
```sql
uid TEXT NOT NULL, target_uid TEXT NOT NULL,
call_notify INTEGER DEFAULT 0,
PRIMARY KEY (uid, target_uid)
```

---

## 6. 通知

### announcements
系统公告 / 系统通知。
```sql
id INTEGER PRIMARY KEY AUTOINCREMENT,
publisher TEXT, unit TEXT, title TEXT, content TEXT,
attachments TEXT, created_at REAL,
modified_at REAL, modifier TEXT,
is_read INTEGER DEFAULT 0,     -- 后加
target_uid TEXT,                -- 后加（通知目标用户）
is_locked INTEGER DEFAULT 0    -- 后加（防误删）
```
