# 通话权限控制

## 概述

用户可以在聊天室详情和私聊详情中，控制是否接收来自该聊天室/该私聊对象的语音/视频通话邀请。

---

## 1. 聊天室通话权限

### 设置位置
聊天室详情界面（`chatDetailModal`）中增加一个选项。

### 存储方式
在 `group_members` 表中增加 `call_notify` 列（per-user per-chat-room）：
```sql
ALTER TABLE group_members ADD COLUMN call_notify INTEGER DEFAULT 0;
```
- 每个成员可以独立设置是否接收某个聊天室的通话邀请
- 默认值为 `0`（不弹窗）

### 选项
- 标签：**"接收该聊天室的通话邀请"**
- 类型：开关 / checkbox
- 默认值：**关**（不弹窗）

### 行为
- 开关 = **关**：发起方在群聊通话成员勾选界面中，该成员显示为灰色，不可勾选
- 开关 = **开**：正常接收来电弹窗

### 系统聊天室强制规则
系统自动创建的课程聊天室、班级聊天室，此选项**强制开启**，且**不可由用户关闭**（开关置灰，显示"系统聊天室强制开启"）

系统聊天室的判断依据：`groups_chat` 表的 `creator` 字段值为 `"system"`。系统自动创建课程聊天室时 `creator` 设为 `'system'`，用户创建的聊天室 `creator` 为当前用户的 uid。详见 `ensure_default_groups()`（`app.py:1576`）。

## 2. 私聊通话权限

### 设置位置
成员详情界面（`memberInfoModal`）中增加一个选项，位于"聊天/拉黑/好友"按钮区域上方。

### 存储方式
新增 `call_preferences` 表：
```sql
CREATE TABLE call_preferences (
    uid TEXT NOT NULL,
    target_uid TEXT NOT NULL,
    call_notify INTEGER DEFAULT 0,
    PRIMARY KEY (uid, target_uid)
);
```

### 选项
- 标签：**"接收该联系人的通话邀请"**
- 类型：开关 / checkbox
- 默认值：**关**（不弹窗）

### 行为
- 开关 = **关**：对方发起通话时，发起方检查权限失败，提示"你没有通话权限！"
- 开关 = **开**：正常接收来电弹窗

---

## 3. 通话发起流程（含权限检查）

```
发起方点击通话按钮
  ├─ 群聊：
  │    → 弹出成员选择界面
  │    → 从 chat detail 获取各成员 call_notify 状态
  │    → call_notify=0 的成员灰色不可选
  │    → 用户勾选有权限的成员
  │    → 检查在线状态（有成员在线则继续）
  │    → 对有权限且在线的成员逐一发送 invite
  │
  └─ 私聊：
       → 检查对方在线？ 不在线 → "对方未在线"，终止
       → 查 call_preferences(对方uid, 发起方uid).call_notify
       → = 0 → "你没有通话权限！"，终止
       → = 1 → 发送 invite
```

## 4. 前端改动

### 聊天室详情（chatDetailModal）
成员列表下方新增一行：
```
  ☐ 接收该聊天室的通话邀请
  (系统聊天室: 强制开启)  ← 置灰不可操作
```

### 私聊详情（memberInfoModal）
在"聊天/拉黑/好友"按钮区域上方新增一行：
```
  ☐ 接收该联系人的通话邀请
```

### 群聊通话成员勾选（需改动现有界面）
`showGroupCallMemberPicker`（当前用动态生成 HTML 实现）需改为：

1. 调用 `GET /api/groups/<id>/detail` 获取成员列表（含 `call_notify` 字段）
2. 渲染成员选项时：
   - `call_notify=1` → 正常可选
   - `call_notify=0` → 选项灰色（`color:var(--text-muted);background:#f1f5f9`），checkbox `disabled`
   - 系统聊天室（`creator='system'`）不影响此界面，此处只反映各成员的开关状态
3. 底部显示选中/总成员数：`已选择 X 人（共 Y 人有权限）`
4. "邀请"按钮对无权限选择的情况保持禁用

### 私聊通话发起
`startCall` 中调用 `/api/call/invite`，后端返回 400 时提示 `"你没有通话权限！"`。

---

## 5. 后端改动

### 数据库
1. `ALTER TABLE group_members ADD COLUMN call_notify INTEGER DEFAULT 0`
2. 新增 `call_preferences` 表（私聊通话权限，per-user）

### API
1. `GET /api/groups/<id>/detail` — 返回的成员列表包含 `call_notify` 字段
2. `POST /api/groups/<id>/call-setting` — 设置当前用户在该聊天室的 `call_notify`
3. `GET /api/call/preference?with=<uid>` — 获取当前用户对某联系人的设置
4. `POST /api/call/preference` — 设置当前用户对某联系人的 `call_notify`
5. `POST /api/call/invite` — 私聊发起时检查 `call_preferences(目标uid, 发起方uid)`，无权则返回 400 + "你没有通话权限！"
