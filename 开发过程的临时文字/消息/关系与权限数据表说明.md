# 建议
friends 表，blacklist 表，call_preferences 表合并为一个表，命名为用户关系，其字段如下
```sql
CREATE TABLE friends (
    uid TEXT,          -- 用户 A
    friend_uid TEXT,   -- 用户 B（A 的好友）
        -- 成为好友的时间
        -- A拉黑B指示字段
        -- B拉黑A指示字段
        -- A设置的通话权限指示字段
        -- B设置的通话权限只是字段
);
```
# 关系与权限数据表说明

## 好友关系

### friends 表
```sql
CREATE TABLE friends (
    uid TEXT,          -- 用户 A
    friend_uid TEXT,   -- 用户 B（A 的好友）
    created_at REAL,   -- 成为好友的时间
    PRIMARY KEY (uid, friend_uid)
);
```
- 双向好友关系需要两条记录，例如 `(A, B)` 和 `(B, A)`
- `GET /api/friends` 返回当前用户 uid 对应的所有 `friend_uid`

### friend_requests 表
```sql
CREATE TABLE friend_requests (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    from_uid TEXT,     -- 申请发起方
    to_uid TEXT,       -- 申请接收方
    message TEXT,      -- 申请备注
    status TEXT DEFAULT 'pending',  -- pending / approved / rejected
    created_at REAL,
    is_read INTEGER DEFAULT 0
);
```
- `from_uid` 向 `to_uid` 发送好友申请
- 通知展示时前端在 id 前加 `fr_` 前缀

## 黑名单

### blacklist 表
```sql
CREATE TABLE blacklist (
    uid TEXT,           -- 拉黑者
    blocked_uid TEXT,   -- 被拉黑者
    PRIMARY KEY (uid, blocked_uid)
);
```
- 单向屏蔽，A 拉黑 B 不影响 B 拉黑 A
- 拉黑后双方不可互发消息，被拉黑者尝试发送时提示"你已被此用户拉黑"

## 聊天室成员

### group_members 表
```sql
CREATE TABLE group_members (
    group_id TEXT,          -- 聊天室 ID
    uid TEXT,               -- 用户 ID
    role TEXT DEFAULT 'member',  -- member / manager(管理员) / admin(群主)
    joined_at REAL,
    call_notify INTEGER DEFAULT 0,  -- 通话权限（0=关闭，1=开启）
    PRIMARY KEY (group_id, uid)
);
```

#### call_notify 字段
- **0**（默认）→ 不接收该聊天室的通话邀请，发起方的成员勾选界面中该成员灰色不可选
- **1** → 可被邀请通话，正常接收来电弹窗
- 系统聊天室（`groups_chat.creator = 'system'`）强制为 1，不可修改
- 由 `POST /api/groups/<id>/call-setting` 设置

## 私聊通话权限

### call_preferences 表
```sql
CREATE TABLE call_preferences (
    uid TEXT NOT NULL,           -- 设置者
    target_uid TEXT NOT NULL,    -- 针对哪个联系人
    call_notify INTEGER DEFAULT 0,  -- 0=关闭，1=开启
    PRIMARY KEY (uid, target_uid)
);
```
- 记录"我"（uid）是否允许"对方"（target_uid）向我发起通话
- 没有记录时默认关（`= 0`）
- 发起私聊通话时后端检查此表：查 `call_preferences(target_uid, 发起方uid)`
- 由 `GET/POST /api/call/preference` 读写

## 关系总览

| 场景 | 存储位置 | 检查时机 | 无权限提示 |
|------|----------|----------|------------|
| 群聊通话权限 | `group_members.call_notify` | 发起方前端成员勾选界面过滤 | 灰色不可选 + "(未开启)" |
| 私聊通话权限 | `call_preferences` | 发起方 `POST /api/call/invite` | "你没有通话权限！" |
| 好友关系 | `friends` | 私聊通话发起前检查 | "你不是该用户的好友" |
| 黑名单屏蔽 | `blacklist` | 发送消息时后端检查 | "你已被此用户拉黑" |
