# 群组功能实现说明

本文档基于 `开发过程的临时文字/群组功能完善要求.md` 中描述的 7 项需求，结合实际代码实现，细化功能逻辑。

---

## 1. 创建聊天室功能优化

### 需求
优化创建聊天室功能，可勾选参与聊天的成员（范围为所有系统用户），可自定义聊天室名称。

### 实现

**后端** (`app.py:create_chat_in_group`):
- 修复了 `group.get('category')` 导致的 `AttributeError` bug（`sqlite3.Row` 无 `.get()` 方法），改为 `group['category']` + `if group['category'] else '自定义'`
- 创建聊天室时，接收 `members` 参数，将选中成员以 `'member'` 角色添加到 `group_members` 表
- 创建者以 `'admin'` 角色自动加入
- 创建后自动生成系统消息：「XXX 创建了聊天室」

**前端** (`groups.html:showCreateChatModal` / `createChatInGroup`):
- 弹窗中显示所有系统用户（排除当前用户），带复选框供勾选
- 发送 `POST /api/user-groups/{groupId}/create-chat` 时携带 `members` 数组

## 2. 聊天室功能优化

### 2.1 进入/退出通知

**需求**: 成员进入和退出聊天室后，在聊天室显示一条提示信息。

**实现**:

**后端**:
- 创建聊天室时：插入 `msg_type='system'` 的消息「XXX 创建了聊天室」
- 退出聊天室时 (`leave_group`)：插入 `msg_type='system'` 的消息「XXX 退出了聊天室」
- 踢出成员时 (`kick_from_chat`)：插入 `msg_type='system'` 的消息「XXX 已被移出聊天室」
- 系统消息的 `sender='system'`，查询时使用 `LEFT JOIN users` + `COALESCE(u.name, '系统')` 确保系统消息不被过滤

**前端** (`groups.html:loadGroupMessages`):
- `msg_type === 'system'` 的消息渲染为居中灰色文字，不使用气泡样式

### 2.2 聊天室详情界面

**需求**: 聊天界面右上角显示「... 详情」按钮，点击后展示聊天室详情界面。

**后端 API** (`app.py`):

| 方法 | 路由 | 功能 | 权限 |
|------|------|------|------|
| GET | `/api/groups/{id}/detail` | 聊天室信息+成员列表 | 成员 |
| POST | `/api/groups/{id}/leave` | 退出聊天室 | 非群主 |
| POST | `/api/groups/{id}/invite` | 邀请成员 | 成员 |
| POST | `/api/groups/{id}/kick` | 踢出成员 | 群主(admin) |
| PUT | `/api/groups/{id}/rename` | 修改名称 | 群主/admin、manager |
| POST | `/api/groups/{id}/admin` | 设置/取消管理员 | 群主(admin) |
| POST | `/api/groups/{id}/announcement` | 发布公告 | 群主/admin、manager |

**角色体系** (`group_members.role`):
- `admin` — 群主，创建聊天室时自动获得，唯一可管理管理员
- `manager` — 管理员，由群主指定，可改名、发公告
- `member` — 普通成员

**前端** (`groups.html`):
- `enterChatRoom()` 将 chat header 渲染为带「... 详情」按钮的结构
- `showChatDetail()` 加载详情弹窗，包含：
  - 聊天室名称 + 群主/管理员操作按钮（重命名、公告）
  - 成员列表（头像、姓名、角色标识🔑/🛡️）
  - 群主可见的「踢出」「设为管理/取消管理」操作
  - 点击成员 → 成员信息弹窗
  - 「邀请成员」按钮 → 弹窗选择用户 → POST invite
  - 「退出聊天室」按钮（红框）+ 确认对话框
- `leaveChatRoom()`: 确认后调用 leave API，关闭弹窗并返回群组详情

## 3. 成员信息界面

### 需求
点击聊天室成员头像后（或右键消息发送者名称），显示成员信息界面，内容包括：
- 成员姓名、学号/工号
- 角色（学生/教师）
- 个人简介
- 聊天按钮（跳转到与该成员的私聊）
- 拉黑按钮

### 实现

**后端**:
- `GET /api/user/{uid}` 返回用户公开信息

**前端** (`groups.html`):
- `showMemberInfo(el)` 读取 `el.dataset` 获取 uid/name/role，渲染弹窗
- `showMemberInfoFromPrivate()` 私聊右上角详情入口
- 弹窗内容：头像、姓名、uid、角色、简介、聊天按钮、拉黑按钮
- `memberInfoStartChat()` 关闭弹窗并跳转到私聊
- `memberInfoToggleBlock()` 切换拉黑状态

**触发方式**:
| 触发位置 | 事件 | 方式 |
|----------|------|------|
| 聊天室详情成员列表 | 左键点击 | `showMemberInfo(this)` |
| 群聊消息发送者名称 | 左键/右键 | `onclick` / `oncontextmenu` |
| 私聊消息发送者名称 | 左键/右键 | `onclick` / `oncontextmenu` |
| 群组侧栏成员列表 | 右键 | `oncontextmenu` |
| 私聊右上角 | 左键 | `showMemberInfoFromPrivate()` |

### 需求
在聊天室的聊天界面右键某用户头像/名称，显示成员信息界面。

## 6. 用户简介字段

### 需求
为数据库的 `users` 表增加 `description` 字段，用于存储用户简介，默认为空，在个人设置界面可编辑。

### 实现

**数据库** (`app.py:init_db`):
- `ALTER TABLE users ADD COLUMN description TEXT DEFAULT ''`

**API**:
- `GET /api/userinfo` → 返回当前用户的 `description`
- `PUT /api/userinfo` → 接受 `description` 参数并更新
- `GET /api/user/{uid}` → 返回指定用户的公开信息（含 description）

**前端** (`profile.html`):
- 在密码确认输入框下方添加「个人简介」文本框（maxlength=200）
- 页面加载时从 `/api/userinfo` 获取简介
- 保存时提交 `description`，空值也允许（用于清空简介）

## 7. 拉黑功能

### 需求
拉黑某用户后，不会看到该用户发送的消息，不会接收到该用户的聊天室邀请。

### 实现

**后端** (`app.py`):
- `blacklist` 表 (`uid`, `blocked_uid`, PRIMARY KEY)
- `GET /api/blacklist` → 返回当前用户的拉黑列表
- `POST /api/blacklist/add` → 拉黑用户
- `POST /api/blacklist/remove` → 取消拉黑

**前端** (`groups.html`):
- 初始化时调用 `loadBlacklist()` 缓存黑名单
- `loadPrivateMessages()`: 使用 `await api("/api/blacklist")` 获取黑名单，过滤掉 `blockedUids.includes(m.sender)` 的消息
- `loadGroupMessages()`: 同上，过滤黑名单用户的消息
- 成员信息弹窗中「拉黑/取消拉黑」按钮，切换时更新按钮样式
