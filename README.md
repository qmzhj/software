# 校园通讯平台（最小可运行版本）

## 功能说明

本版本实现了用户注册、登录、登出功能。

- 注册：输入学号/工号、姓名、密码；系统自动判定学生或教职工角色。
- 登录：密码错误5次后锁定30分钟；登录成功获取 Token。
- 登出：清除本地 Token，返回登录页。

## 运行环境

- Windows 11 家庭中文版（或其他 OS）
- Python 3.12.3 及以上

## 安装依赖

打开命令行（cmd 或 PowerShell），进入项目目录，执行：
pip install flask

## 启动服务

在项目目录执行：
python app.py

看到 `Running on http://0.0.0.0:5000` 后，打开浏览器访问 `http://localhost:5000`。

## 使用方法

1. 在“注册”标签页输入学号/工号、姓名、密码进行注册。
2. 切换到“登录”标签页，用刚注册的账号登录。
3. 登录成功后显示主界面，点击“登出”返回。
